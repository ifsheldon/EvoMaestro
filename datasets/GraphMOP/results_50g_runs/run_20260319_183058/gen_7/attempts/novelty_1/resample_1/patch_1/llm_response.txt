<DESCRIPTION>
This approach is fundamentally different from the current method. Rather than computing optimal paths from each source individually with a single heuristic edge weight metric, this algorithm flips the traversal direction. Since there are many sources but only a few servers, it runs multiple Reverse Dijkstras from each server using several different Pareto-optimality weights (emphasizing latency vs. energy vs. hop bounds). This massively reduces Dijkstra overhead and compiles a wealthy precomputed candidate set of (server, path) pairs for each task source.

Subsequently, a dynamic fast-swapping Simulated Annealing local-search metaheuristic optimizes the assignment. The objective function strictly mirrors system-wide latency and energy, using properly scaled M/M/1 wait penalties for servers and heavy soft-penalties for capacity violations. Fast $O(1)$ incremental objective tracking lets the simulated annealing explore hundreds of thousands of neighboring configurations, and the simulated temperature smoothly decays precisely scaled to the runtime bound.
