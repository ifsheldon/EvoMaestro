This approach replaces generic shortest-path edge scaling with theoretically sound path weights centered on average payload, perfectly aligning the Dijkstra path selection with the network objective. Next, we replace the single-pass broad local search with an Iterative Best Response (IBR) load management algorithm. By using mathematically precise surrogate derivatives for both queue delay and system energy, we assign initial server allocations and iteratively target explicitly "hot" (highly stressed) servers. Unburdening the worst localized bottlenecks monotonically pushes the system globally into a highly balanced Pareto-optimal local minimum efficiently over multiple targeted relaxation passes.
