<DESCRIPTION>
Update the task assignment logic to use a more accurate marginal cost function. Instead of a heuristic score that only considers the task's own latency, we now calculate the marginal increase in total system latency (including the congestion externality on other tasks at the same server) and total system energy. This aligns the assignment decisions directly with the global optimization objectives.

    server_load = {srv: 0.0 for srv in server_nodes}
    server_arr = {srv: 0.0 for srv in server_nodes}
    server_users = {srv: 0 for srv in server_nodes}

    for s in ranked_sources:

            mu = float(mu)

            if pred_load >= 0.992 * mu:
                continue
