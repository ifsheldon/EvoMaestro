<DESCRIPTION>
The previous routing logic used a heuristic scoring function that didn't fully capture the marginal impact of adding a task to the system's total latency and energy. This update:
1.  Re-orders the precomputation to calculate `avg_payload` first, allowing it to be used for more accurate edge selection and Dijkstra weights.
2.  Updates the edge selection and Dijkstra weights to use the objective's weight (Latency + 0.5 * Energy).
3.  Replaces the heuristic assignment score with a proper marginal cost calculation. The marginal latency includes both the task's transmission latency and the increase in queueing delay for all tasks at the chosen server. The marginal energy includes routing energy, dynamic compute energy, and idle power (if the server was previously empty).
4.  Applies this consistent marginal cost logic to both the initial greedy assignment and the local search refinement.
</DESCRIPTION>
