<DESCRIPTION>
The novel approach implements a regret-aware greedy assignment strategy combined with a high-fidelity marginal cost model. 

Key insights:
1. **Marginal Cost Model**: Instead of simple per-task metrics, the algorithm calculates the marginal impact of each assignment on the *total* system latency and energy. This includes the change in queueing delay for all tasks at a server and the non-linear change in server dynamic power.
2. **Regret-Aware Ordering**: Sources are prioritized based on "regret"—the difference between the best and second-best server options. This ensures that sources with limited efficient routing options are placed before those that can be flexibly assigned.
3. **Diverse Path Generation**: Multiple Dijkstra trees are precomputed from each server using different edge weight modes (latency-focused, energy-focused, balanced, and capacity-aware) to provide a rich set of candidate paths for each source-server pair.
4. **Iterative Refinement**: A multi-pass local improvement phase re-evaluates each assignment in the context of the final system load, allowing tasks to migrate to better servers or paths as the global state stabilizes.

    edges,
    server_nodes,
    task_sources,

    # ---------- Graph and Edge Attributes ----------
    graph = [[] for _ in range(num_nodes)]
    edge_attr = {}
    for u, v, lat, ene, cap in edges:
        graph[u].append((v, lat, ene, cap))
        graph[v].append((u, lat, ene, cap))
