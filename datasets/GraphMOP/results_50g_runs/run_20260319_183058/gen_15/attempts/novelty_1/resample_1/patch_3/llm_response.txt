<DESCRIPTION>
This algorithm implements a robust multi-objective task routing strategy by combining marginal cost assignment with a regret-inspired priority policy and iterative refinement.

Key features:
1.  **Diverse Candidate Path Generation**: For each task source, it generates multiple candidate paths to all available servers using Dijkstra's algorithm with varying latency-energy trade-off weights (λ). This ensures the search space includes both the fastest paths and the most energy-efficient ones.
2.  **System-Wide Marginal Cost Analysis**: Instead of simple greedy assignment, it calculates the marginal increase in the global objective function (Latency + 1.5 * Energy). This includes the increased queueing delay experienced by all tasks already assigned to a server when a new task is added, as well as the server's idle and dynamic power consumption.
3.  **Heavy-First Priority Heuristic**: Tasks are ordered by their total compute load (arrival rate * compute demand). This "heavy-first" approach, combined with subsequent local search, effectively addresses the "regret" of large tasks that have fewer viable high-quality options.
4.  **Iterative Best-Response Refinement**: A local search phase iteratively re-evaluates each task's assignment, moving tasks to alternative candidate paths if they reduce the total system cost, effectively reaching a better multi-objective equilibrium.
5.  **Robust Queueing Model**: Uses an M/M/1-style queueing delay with a linear expansion beyond 99% utilization to maintain stability and provide a meaningful gradient for the optimization process.
