<DESCRIPTION>
The algorithm uses a marginal-cost-based greedy assignment followed by an iterative local search to minimize the combined latency and energy objectives. 

Key features:
1.  **Marginal Cost Function**: Instead of simple per-task metrics, the assignment and local search use a global marginal cost that accounts for the impact of a task on *all* other tasks sharing the same server. This includes the change in total queueing delay ($N/(\mu - L)$) and the discrete impact of server idle power.
2.  **Multi-Objective Dijkstra**: A scalarized weight $(latency + 0.8 \cdot energy)$ is used during pathfinding to find paths that naturally balance both objectives.
3.  **Iterative Refinement**: A best-response local search iteratively reassigns tasks to servers that minimize the total system cost, effectively handling the non-linear queueing delay and discrete idle power costs.
4.  **Robust Queueing Model**: The cost function includes a safety margin and a high penalty for server saturation to ensure stability and low latency.
