<DESCRIPTION>
This implementation merges the most effective strategies from the prior programs:
1. **Path Diversity**: Retains the `alternative_path_with_penalty` function to find non-tree alternatives, and introduces a 4th "hop-focused" Dijkstra mode to generate shorter paths, reducing both transmission latency and routing energy.
2. **True Marginal Costs**: Introduces a `marginal_qd` penalty. Adding a task to a server increases the queueing delay for *all* other tasks on that server. By scaling the task's queueing delay by `(1.0 + 0.4 * rho / (1 - rho))`, the algorithm correctly anticipates this systemic latency increase, leading to far superior load balancing. It also retains the exact marginal energy cost (`ce_after - ce_before`).
3. **Global Multi-Pass Refinement**: Replaces the restricted server-focused repair pass with a comprehensive multi-pass local improvement phase over *all* ranked sources. This allows tasks to continuously migrate to better server-path combinations until the system reaches a stable local optimum.

    Graph multi-objective routing problem.

    {

            "server": server_node,

    }
    """
    import heapq

    # ---------- Graph build ----------
    graph = [[] for _ in range(num_nodes)]
    edge_attr = {}
    for u, v, base_latency, energy_cost, capacity in edges:
        graph[u].append((v, base_latency, energy_cost, capacity))
        graph[v].append((u, base_latency, energy_cost, capacity))
        key = (u, v) if u < v else (v, u)
        edge_attr[key] = (base_latency, energy_cost, capacity)

    def edge_weight(mode, lat, ene, cap):
        cap_term = 1.0 / (cap + 1e-9)
        if mode == 0:  # latency-focused
            return lat + 0.03 * cap_term + 0.08 * ene
        if mode == 1:  # energy-focused
            return ene + 0.02 * lat + 0.03 * cap_term
        if mode == 2:  # balanced
            return lat + 0.30 * ene + 0.04 * cap_term
        # hop-focused / capacity-focused
        return lat + 0.15 * ene + 0.10 * cap_term + 0.2

    def dijkstra_from_root(root, mode):
        dist = [float("inf")] * num_nodes
        parent = [-1] * num_nodes
        dist[root] = 0.0
        parent[root] = root
        heap = [(0.0, root)]

        while heap:
            d, u = heapq.heappop(heap)
            if d != dist[u]:
                continue
            for v, lat, ene, cap in graph[u]:
                w = edge_weight(mode, lat, ene, cap)
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    parent[v] = u
                    heapq.heappush(heap, (nd, v))
        return dist, parent
