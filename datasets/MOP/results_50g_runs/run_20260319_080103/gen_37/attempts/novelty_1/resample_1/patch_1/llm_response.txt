<DESCRIPTION>
Upgrade base attraction to be conflict-aware. Instead of adding independent offsets for school and base, we first apply the school repulsion to the baseline, and then apply a proportional pull towards the base station from the *current* displaced position. To prevent the base attraction from pulling the drone back into the school's noise zone, we modulate the base pull strength inversely with the school's influence (`w_school`). We also increase the base pull rate and school repulsion amplitude to better match the successful dynamic programming approach's prioritization of F2 and F3.
