<DESCRIPTION>
The `adaptive_two_stage_projection` algorithm implements a direct analytical construction of the drone path based on the two-stage potential field recommendation. 

1. **Broad Signal Alignment (F3)**: It first calculates a base station attraction amplitude. By determining the displacement needed from the linear path at the base station's x-coordinate, it uses a wide Gaussian kernel to ensure the path stays close to the base station for optimal signal coverage.
2. **Clearance-Aware School Repulsion (F2)**: Following the specific recommendation, it estimates the path's height at the school's x-coordinate *after* the base pull is factored in. It then applies an adaptive repulsion amplitude: `amp = min(52.0, max(32.0, 31.0 + 115.0 / (clearance + 5.5)))`. This ensures the school noise penalty is minimized precisely where needed without causing excessive distance.
3. **Harmonic Smoothness (F1)**: The final path is synthesized by combining the linear baseline with the Gaussian fields, all modulated by a sinusoid taper. This guarantees $C^\infty$ smoothness and ensures the path starts and ends exactly at the required coordinates, minimizing total flying distance.

# EVOLVE-BLOCK-START
import math

def evolve_drone_path(start, end, school, base, num_points):
    """
    Directly constructs a drone path using a two-stage adaptive Gaussian projection.
    Optimizes for distance (F1), school noise (F2), and signal loss (F3).
    """
    if num_points <= 0:
        return []

    x0, y0 = start
    x1, y1 = end
    sx, sy = school
    bx, by = base

    # Longitudinal span
    dx_total = x1 - x0
    safe_dx = max(1e-9, abs(dx_total))
    
    # Handle vertical or near-vertical paths
    if abs(dx_total) < 1e-9:
        return [float(y0 + (y1 - y0) * i / (num_points + 1.0)) for i in range(1, num_points + 1)]

    # --- Stage 1: Base Station Attraction (F3) ---
    # Broad Gaussian field for signal strength
    sigma_base = 0.45 * safe_dx
    
    # Linear height at base station x-coordinate
    t_bx = (bx - x0) / dx_total
    y_lin_bx = y0 + (y1 - y0) * t_bx
    
    # Use a clamped taper to avoid division by zero near endpoints
    taper_bx = math.sin(math.pi * max(0.01, min(0.99, t_bx)))
    
    # Amplitude required to pull the path toward the base station
    # 0.96 factor balances signal strength with path distance
    amp_base = ((by - y_lin_bx) / (taper_bx + 0.01)) * 0.96

    # --- Stage 2: Adaptive School Repulsion (F2) ---
    # Narrow Gaussian field for noise reduction
    sigma_school = 0.15 * safe_dx
    
    # Estimate clearance after base pull to determine push magnitude
    t_sx = (sx - x0) / dx_total
    taper_sx = math.sin(math.pi * max(0.0, min(1.0, t_sx)))
    
    # Gaussian weight of base influence at the school's x-coordinate
    gauss_base_at_sx = math.exp(-0.5 * ((sx - bx) / sigma_base)**2)
    y_est_at_sx = (y0 + (y1 - y0) * t_sx) + (amp_base * gauss_base_at_sx) * taper_sx
    
    # Clearance at sx
    clearance = abs(y_est_at_sx - sy)
    
    # Adaptive amplitude formula: amp = min(52.0, max(32.0, a + b / (clearance + c)))
    push_mag = min(52.0, max(32.0, 31.0 + 115.0 / (clearance + 5.5)))
    dir_school = 1.0 if (y_est_at_sx - sy) >= 0 else -1.0
    amp_school = dir_school * push_mag

    # --- Stage 3: Path Synthesis ---
    ys_output = []
    # Generate num_points internal coordinates
    for i in range(1, num_points + 1):
        x = x0 + i * (dx_total / (num_points + 1.0))
        t = (x - x0) / dx_total
        t_normalized = max(0.0, min(1.0, t))
        
        # Smooth taper ensures the deformation returns to 0 at start and end
        taper = math.sin(math.pi * t_normalized)
        
        # Linear baseline component
        y_lin = y0 + (y1 - y0) * t_normalized
        
        # Displacement fields
        offset_base = amp_base * math.exp(-0.5 * ((x - bx) / sigma_base)**2)
        offset_school = amp_school * math.exp(-0.5 * ((x - sx) / sigma_school)**2)
        
        # Final combined height
        y_final = y_lin + (offset_base + offset_school) * taper
        ys_output.append(float(y_final))

    return ys_output
