<DESCRIPTION>
This algorithm replaces iterative gradient descent with a direct two-stage analytical construction based on the winning logic of Gen 34. 

Key insights:
1. **Prioritized Signal Drop Mitigation (F3)**: Since the signal drop is the largest contributor to the score, the algorithm first computes a wide Gaussian "pull" toward the base station. It determines the amplitude required to align the baseline with the base station's Y-coordinate at its specific X-location, modulated by a sinus taper for smooth endpoint resolution.
2. **Adaptive School Clearance (F2)**: Following the recommendation, the path's height is estimated at the school's X-location *after* the base pull is applied. This "clearance" is used to calculate a precise school repulsion magnitude using the non-linear adaptive formula: `amp = min(52, max(32, 31 + 115 / (clearance + 5.5)))`. This ensures the noise penalty is minimized without unnecessarily increasing the path length.
3. **Aerodynamic Smoothness (F1)**: By using Gaussian kernels and a harmonic taper ($sin(\pi t)$), the path maintains $C^\infty$ smoothness and strictly adheres to the start/end points. This minimizes the total flying distance while providing a natural curve that bends away from the school and towards the base station as requested.

# EVOLVE-BLOCK-START
import math

def evolve_drone_path(start, end, school, base, num_points):
    """
    Constructs an optimized drone path using a two-stage adaptive analytical projection.
    
    Optimizes:
    - F1 (Distance): Smooth Gaussian synthesis with sine tapering.
    - F2 (Noise): Adaptive localized repulsion based on predicted clearance.
    - F3 (Signal): Broad Gaussian alignment toward the base station coordinates.
    """
    if num_points <= 0:
        return []

    x0, y0 = start
    x1, y1 = end
    sx, sy = school
    bx, by = base

    # Longitudinal span and basic safety checks
    dx_total = x1 - x0
    safe_dx = max(1e-9, abs(dx_total))
    
    # Handle vertical paths (unlikely in drone scenarios, but good for robustness)
    if abs(dx_total) < 1e-9:
        return [float(y0 + (y1 - y0) * i / (num_points + 1.0)) for i in range(1, num_points + 1)]

    # --- Stage 1: Base Station Attraction (Signal Quality - F3) ---
    # sigma_base covers a broad area to ensure signal coverage along the flight
    sigma_base = 0.45 * safe_dx
    
    # Calculate where the baseline would be at the base's X coordinate
    t_bx = (bx - x0) / dx_total
    # Taper ensures displacement starts/ends at 0. Clamp to prevent division by zero.
    t_bx_clamped = max(0.01, min(0.99, t_bx))
    taper_bx = math.sin(math.pi * t_bx_clamped)
    
    y_lin_bx = y0 + (y1 - y0) * t_bx
    # Determine the amplitude needed to pull the baseline toward the base station Y ('by')
    amp_base = ((by - y_lin_bx) / (taper_bx + 0.001)) * 0.96

    # --- Stage 2: Adaptive School Repulsion (Noise Reduction - F2) ---
    # sigma_school is sharper to provide localized noise avoidance
    sigma_school = 0.15 * safe_dx
    
    # Calculate the current height at school x-location (base pull included)
    t_sx = (sx - x0) / dx_total
    taper_sx = math.sin(math.pi * max(0.0, min(1.0, t_sx)))
    
    # Gaussian influence of base at school's X
    gauss_base_at_sx = math.exp(-0.5 * ((sx - bx) / sigma_base)**2)
    y_at_sx_with_base = (y0 + (y1 - y0) * t_sx) + (amp_base * gauss_base_at_sx) * taper_sx
    
    # Clearance from school
    clearance = abs(y_at_sx_with_base - sy)
    
    # Adaptive amplitude formula from Gen 34 recommendations
    # Provides high force when close, but avoids excessive distance deviation
    push_mag = min(52.0, max(32.0, 31.0 + 115.0 / (clearance + 5.5)))
    dir_school = 1.0 if (y_at_sx_with_base - sy) >= 0 else -1.0
    amp_school = dir_school * push_mag

    # --- Stage 3: Smooth Path Synthesis (Distance - F1) ---
    ys_output = []
    # Generate the internal Y-coordinates for the drone path
    for i in range(1, num_points + 1):
        x = x0 + i * (dx_total / (num_points + 1.0))
        t = (x - x0) / dx_total
        t_normalized = max(0.0, min(1.0, t))
        
        # Superimpose the two Gaussian potential fields onto the linear baseline
        y_lin = y0 + (y1 - y0) * t_normalized
        
        # Harmonic taper ensures the path starts at y0 and ends at y1
        taper = math.sin(math.pi * t_normalized)
        
        offset_base = amp_base * math.exp(-0.5 * ((x - bx) / sigma_base)**2)
        offset_school = amp_school * math.exp(-0.5 * ((x - sx) / sigma_school)**2)
        
        y_final = y_lin + (offset_base + offset_school) * taper
        ys_output.append(float(y_final))

    return ys_output
