<DESCRIPTION>
The `adaptive_two_stage_gaussian_projection` algorithm implements a direct analytical construction of the drone path using a two-stage potential field approach. 
1. **Broad Base Attraction**: It first calculates a broad Gaussian pull toward the base station signal coordinates to minimize signal loss (F3). 
2. **Clearance-Aware School Repulsion**: Following the recommendation, it evaluates the path's clearance from the school *after* the base attraction is applied. It then applies a localized Gaussian push away from the school with an adaptive amplitude: `amp = min(52.0, max(32.0, 30.0 + 110.0 / (clearance + 5.0)))`. This ensures optimal noise reduction (F2) without excessive distance penalties.
3. **Smooth Geometric Synthesis**: The path is synthesized by adding these Gaussian offsets to a linear baseline, multiplied by a sinusoidal taper. This ensures the path is $C^\infty$ smooth and adheres strictly to the start and end points, minimizing total distance (F1).
