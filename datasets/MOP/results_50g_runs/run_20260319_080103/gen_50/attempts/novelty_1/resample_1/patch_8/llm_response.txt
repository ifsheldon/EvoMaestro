<DESCRIPTION>
The `adaptive_clearance_dual_projection` algorithm implements a two-stage analytical deformation of a linear baseline. 
1. **Prioritized Base Alignment (F3)**: It first calculates a broad Gaussian "pull" toward the base station. By determining the amplitude required to reach the base station's Y-coordinate at its specific X-location, it directly targets signal loss reduction.
2. **Post-Alignment School Clearance (F2)**: Following the recommendation from Gen 34, it calculates the path's estimated Y-coordinate at the school's X-coordinate *after* accounting for the base pull. This provides an accurate measure of noise clearance. It then applies an adaptive push amplitude, constrained between 32.0 and 52.0, ensuring optimal noise minimization while preventing excessive distance penalties.
3. **Harmonic Smoothness (F1)**: All deformations are modulated by a sinusoidal taper function and constructed using Gaussian kernels. This ensures the path is C-infinity smooth, minimizes the total flying distance, and strictly adheres to the fixed start and end point constraints.

# EVOLVE-BLOCK-START
import math

def evolve_drone_path(start, end, school, base, num_points):
    """
    Optimizes a drone path to minimize distance (F1), school noise (F2), and signal loss (F3).
    Uses a two-stage analytical model with adaptive Gaussian projection.
    """
    if num_points <= 0:
        return []

    x0, y0 = start
    x1, y1 = end
    sx, sy = school
    bx, by = base

    # Calculate span and handle edge cases
    dx_total = x1 - x0
    safe_dx = max(1e-9, abs(dx_total))
    
    # Handle vertical paths
    if abs(dx_total) < 1e-9:
        return [float(y0 + (y1 - y0) * i / (num_points + 1.0)) for i in range(1, num_points + 1)]

    # Clamping range for stability
    y_low = min(y0, y1, sy, by) - 150.0
    y_high = max(y0, y1, sy, by) + 150.0

    # --- Stage 1: Base Station Attraction (Signal Strength F3) ---
    # Width of the influence (broad reach for signal)
    sigma_base = 0.44 * safe_dx
    
    # Calculate interpolation factor and taper for the base station location
    t_bx = (bx - x0) / dx_total
    t_bx_c = max(0.01, min(0.99, t_bx))
    taper_bx = math.sin(math.pi * t_bx_c)
    
    # Target: Determine amplitude needed to push baseline toward 'by'
    y_lin_bx = y0 + (y1 - y0) * t_bx
    amp_base = ((by - y_lin_bx) / (taper_bx + 0.001)) * 0.96

    # --- Stage 2: Adaptive School Repulsion (Noise Proximity F2) ---
    # Width of the influence (localized for noise)
    sigma_school = 0.14 * safe_dx
    
    # Estimate clearance after base pull to determine push magnitude
    t_sx = (sx - x0) / dx_total
    taper_sx = math.sin(math.pi * max(0.0, min(1.0, t_sx)))
    gauss_base_at_sx = math.exp(-0.5 * ((sx - bx) / sigma_base)**2)
    
    y_est_at_sx = (y0 + (y1 - y0) * t_sx) + (amp_base * gauss_base_at_sx) * taper_sx
    clearance = abs(y_est_at_sx - sy)
    
    # Recommendation from context: Adaptive amplitude function
    # push_mag = min(52.0, max(32.0, a + b / (clearance + c)))
    push_mag = min(52.0, max(32.0, 31.0 + 115.0 / (clearance + 5.5)))
    dir_school = 1.0 if (y_est_at_sx - sy) >= 0 else -1.0
    amp_school = dir_school * push_mag

    # --- Stage 3: Path Synthesis ---
    ys_output = []
    step_size = dx_total / (num_points + 1.0)
    
    for i in range(1, num_points + 1):
        x = x0 + i * step_size
        t = (x - x0) / dx_total
        t_c = max(0.0, min(1.0, t))
        
        # Sine taper ensures the deformation smoothly returns to 0 at start and end
        taper = math.sin(math.pi * t_c)
        
        # Linear baseline
        y_lin = y0 + (y1 - y0) * t_c
        
        # Displacement fields
        offset_base = amp_base * math.exp(-0.5 * ((x - bx) / sigma_base)**2)
        offset_school = amp_school * math.exp(-0.5 * ((x - sx) / sigma_school)**2)
        
        # Combine onto path
        y_final = y_lin + (offset_base + offset_school) * taper
        
        # Final safety clamp
        y_final = max(y_low, min(y_high, y_final))
        ys_output.append(float(y_final))

    return ys_output
