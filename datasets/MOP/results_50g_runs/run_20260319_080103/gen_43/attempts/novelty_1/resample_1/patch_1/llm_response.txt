An excellent way to improve the performance of this potential field approach is to address three subtle but impactful issues in the current implementation:

1. **Endpoint Discontinuities (F1 Penalty):** The current potential field shifts the Y-coordinates even at the very start (`t=0`) and end (`t=1`) of the path. Because the evaluation function expects the path to connect exactly to the `start` and `end` coordinates, this creates massive artificial jumps at the boundaries, severely penalizing the F1 (distance) score. We can fix this by applying an envelope function (like `1.0 - abs(2.0 * t - 1.0)**3`) to the total deviation, forcing the shifts to smoothly decay to zero at the endpoints.
2. **Repulsion Kinks:** The direction of the school repulsion is currently evaluated dynamically against `y_linear`. If the linear path crosses the school's Y-coordinate, the repulsion direction flips instantly, creating a sharp kink in the path. We should calculate a constant direction based on the school's position relative to the linear path at the school's X-coordinate.
3. **Repulsion Shape:** A Gaussian function drops off very quickly. By switching the school repulsion to a Lorentzian function (`1 / (1 + x^2)`), we get fatter tails. This makes the drone start avoiding the school earlier and more gently, resulting in a smoother curve that improves F1 while maintaining excellent F2 (noise) avoidance.
