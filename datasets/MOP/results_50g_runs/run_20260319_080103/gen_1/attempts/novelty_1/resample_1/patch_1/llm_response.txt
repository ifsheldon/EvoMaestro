The proposed algorithm employs a **Potential Field with Gaussian Deformation** approach. Instead of a simple linear interpolation or a rigid geometric fix, this method treats the problem as a physical system where features in the environment exert "forces" on the path.

1.  **Baseline Path:** It starts with a standard linear trajectory to maintain horizontal efficiency.
2.  **Attraction (F3 - Signal Drop):** The base station (70, -30) acts as an attractor. A Gaussian kernel centered at the base station's X-coordinate pulls the path vertically towards the base station's Y-coordinate. This significantly reduces the signal drop penalty (F3) which was the primary cost driver.
3.  **Repulsion (F2 - School Noise):** The school (40, 20) acts as a repulsor. A separate Gaussian kernel pushes the path vertically away from the school. This minimizes noise proximity (F2).
4.  **Gaussian Continuity:** Using Gaussian functions ensures that path modifications are localized and infinitely differentiable (C-infinity continuous). This results in a smooth curve that adds very little total distance (F1) compared to sharp turns or piecewise linear corrections.

By balancing these fields, the algorithm creates a path that "bends" intuitively towards the signal and away from the noise, optimizing all three objectives simultaneously through a sum of localized kernel influences.
