<DESCRIPTION>
The algorithm uses an **Analytical Gaussian Spline Solver**. Instead of applying iterative physical forces or simple heuristics, it constructs the trajectory as a linear interpolation baseline plus a linear combination of two "pinned" Gaussian basis functions. 

1. **Pinned Gaussian Basis**: It uses Gaussian kernels that are mathematically forced to be exactly zero at the start and end points of the flight. This ensures the boundary conditions (reaching the destination) are always met with $C^\infty$ smoothness, minimizing the flying distance (F1).
2. **2x2 Analytical Solution**: It identifies two target displacements: one at the school's X-coordinate (to stay 35 units away from the noise source) and one at the base station's X-coordinate (to reach target signal strength). It then sets up and solves a 2x2 system of linear equations to find the exact amplitudes for the school-repulsion and base-attraction kernels.
3. **Optimized Parameters**: It uses relatively broad kernels ($\sigma = 22\%$ of the total span) to ensure the path doesn't have sharp turns, which keeps the total distance (F1) efficient while satisfying both spatial constraints (F2 and F3).
</DESCRIPTION>

# EVOLVE-BLOCK-START
def evolve_drone_path(start, end, school, base, num_points):
    """
    无人机连续空间多目标折线优化：
    使用“销钉高斯基函数解析求解器”(Pinned Gaussian Basis Solver)。
    - F1: 保证 C-infinity 连续，通过宽基函数最小化曲率。
    - F2: 求解线性方程组，精确计算离校目标的偏移量。
    - F3: 求解线性方程组，确保轨迹在基站处有最低信号损失。
    """
    import math

    x0, y0 = start
    x1, y1 = end
    xs, ys = school
    xb, yb = base

    if num_points <= 0:
        return []

    dx_total = x1 - x0
    if abs(dx_total) < 1e-12:
        # 极端情况：X 轴无跨度，按 Y 轴线性插值
        step = (y1 - y0) / (num_points + 1)
        return [float(y0 + (i + 1) * step) for i in range(num_points)]

    # 1. 设置平滑度参数
    span = abs(dx_total)
    sigma = 0.22 * span  # 较大的 sigma 保证 F1 指标

    def get_y_lin(x):
        # 线性插值基准
        t = (x - x0) / dx_total
        return y0 + t * (y1 - y0)

    def get_pinned_basis(x, mu):
        # 计算在 x0 和 x1 处为 0 的高斯偏移函数
        t = (x - x0) / dx_total
        phi = math.exp(-0.5 * ((x - mu) / sigma)**2)
        phi0 = math.exp(-0.5 * ((x0 - mu) / sigma)**2)
        phi1 = math.exp(-0.5 * ((x1 - mu) / sigma)**2)
        # 通过线性减除，确保端点为 0
        return phi - (phi0 + t * (phi1 - phi0))

    # 2. 确定目标偏移量
    # 基站目标：正好落在基站 Y 坐标上
    target_dip_b = yb - get_y_lin(xb)
    
    # 学校目标：远离中心（通常至少保持 32-35 单位距离）
    ys_lin = get_y_lin(xs)
    # 如果学校在基准线上方，向下推；反之亦然
    target_ys = (ys - 34.0) if ys >= ys_lin else (ys + 34.0)
    target_dip_s = target_ys - ys_lin

    # 3. 求解线性方程组 M*A = T
    # Pss*As + Psb*Ab = Ts
    # Pbs*As + Pbb*Ab = Tb
    p_ss = get_pinned_basis(xs, xs)
    p_sb = get_pinned_basis(xs, xb)
    p_bs = get_pinned_basis(xb, xs)
    p_bb = get_pinned_basis(xb, xb)

    det = p_ss * p_bb - p_sb * p_bs
    if abs(det) < 1e-6:
        # 若退化（如 xs 极靠近 xb），退回到简单的加权处理
        amp_s = target_dip_s / (p_ss + 1e-5)
        amp_b = (target_dip_b - amp_s * p_bs) / (p_bb + 1e-5)
    else:
        # Cramer's Rule
        amp_s = (target_dip_s * p_bb - target_dip_b * p_sb) / det
        amp_b = (p_ss * target_dip_b - p_bs * target_dip_s) / det

    # 4. 限制振幅防止过度扰动 F1
    amp_limit = 65.0
    amp_s = max(-amp_limit, min(amp_limit, amp_s))
    amp_b = max(-amp_limit, min(amp_limit, amp_b))

    # 5. 生成采样点
    y_coords = []
    for i in range(num_points):
        # 计算 X 坐标
        px = x0 + (i + 1) * dx_total / (num_points + 1)
        # 叠加线性部分与两个偏移基函数
        y_val = get_y_lin(px) + amp_s * get_pinned_basis(px, xs) + amp_b * get_pinned_basis(px, xb)
        y_coords.append(float(y_val))

    return y_coords
# EVOLVE-BLOCK-END
