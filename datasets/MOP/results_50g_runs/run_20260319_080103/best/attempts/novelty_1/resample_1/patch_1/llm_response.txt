<DESCRIPTION>
1. **Remove the `env` smooth scaling**: The previous introduction of the sine envelope function strictly bounded modifications near the endpoints to 0. This dramatically harmed the base signal metrics (F3) and school noise metrics (F2) when these POIs were nearer to the course's start/end.
2. **Reorder Operations**: Instead of dodging the school first and then drawing towards the base (which could re-steer the path right back into the school thereby hurting F2), we now pull the trajectory toward the base *first*. Afterwards, we firmly repulse it away from the school so avoidance takes correct priority and ensures minimum F2 noise penalization.
3. **Consistent Dodge Direction**: To guarantee a clean dodge and prevent mid-point switching or jitter if the path hugs the school's noise zone, we calculate `global_push_dir` right at the `sx` mark based on where the base attraction *would* naturally drift the drone. This ensures the curve bulges smoothly to one valid side.
4. **Broadened Signal Capture**: Tuning `sigma_b2` wider enables the drone to hold a strong signal over a broader region and tuning `w_s` push value slightly higher directly protects against noise overlaps.
</DESCRIPTION>
