# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- **The current best pattern remains full-path dynamic programming with transition-level scoring, and the new evidence strengthens that conclusion.**  
  The **Dynamic Programming Grid Path (Gen 15)** is still the clear leader at **17.25** with **F1=1.21, F2=0.46, F3=31.12**. Its key implementation choice is optimizing each waypoint jointly over an **81-level y-grid**, with costs attached to **segment transitions** rather than independently shaping each point. This continues to outperform all newer correct programs, including **Guided-Band DP Drone Path (Gen 35, 24.44)** and every Gaussian variant summarized here.

- **Midpoint-aware segment costs are strongly validated by the best program’s metrics.**  
  In the current best code, each segment includes:
  - Euclidean length,
  - school-noise penalty at the **segment midpoint**,
  - base-signal penalty at the **segment midpoint**.  
  This is a concrete implementation advantage over pointwise Gaussian bending methods such as **Gaussian Potential Field Drone Path (Gen 33, 29.77)** and **Sequential Gaussian Bend Heuristic (Gen 29, 31.31)**, which still left **F3** much higher despite reasonable **F1/F2**.

- **Bounded, geometry-aware discretization remains an especially effective refinement.**  
  The current best expands the y-grid only when the school/base lie within about **±200** of the start-end corridor, then adds a **±60** margin and keeps a fixed **M=81** resolution. This selective expansion appears to preserve useful search resolution while still allowing meaningful detours. That targeted discretization continues to outperform broader continuous-space shaping used in **Geometry-Aware Potential Field Path (Gen 36, 37.87)** and the Gaussian family.

- **Light post-optimization smoothing works when applied after a globally optimized discrete path.**  
  The best program’s **3-pass Laplacian smoothing with alpha=0.4** preserves the strategic DP shape while removing grid artifacts. This remains more successful than using smoothness or continuous refinement as the primary generator, as seen in **Geometry-Aware Potential Field Path (Gen 36)**, whose much heavier optimization still scored **37.87**.

## Ineffective Approaches
- **Sequential Gaussian school-repulsion/base-attraction shaping continues to underperform because it cannot reduce F3 enough.**  
  The newly summarized Gaussian family all passed validation but remained well behind the current best:
  - **Gaussian School-Repulsion Base-Attraction Path (Gen 25): 31.59**
  - **Sequential Gaussian Bend Heuristic (Gen 29): 31.31**
  - **Gaussian Potential Field Drone Path (Gen 33): 29.77**  
  In each case, evaluator feedback explicitly identified **signal loss (F3)** as the dominant weakness, confirming the earlier pattern that local deformations do not match joint path optimization.

- **Adding more Gaussian stages or recovery passes did not solve the core weakness.**  
  **Gen 33** introduced a wide base attraction, narrow school repulsion, and a final recovery pull near the base, yet still only reached **29.77** with **F3=31.28**. That is slightly better than some other Gaussian variants on total score, but still far behind the current best **17.25**, showing that stacking local correction phases is weaker than optimizing the entire path globally.

- **Continuous iterative optimization with multiple energy terms remains a poor tradeoff despite sophistication.**  
  **Geometry-Aware Potential Field Path (Gen 36)** used **180 iterations of decayed-gradient descent** with school avoidance, base attraction, path length, and smoothness terms, but scored **37.87** with **F2=0.92** and **F3=33.42**. - **A weaker DP structure can still lose badly if the search is too restricted or over-regularized.**  
  **Guided-Band DP Drone Path (Gen 35)** is important because it uses DP, yet only scored **24.44**, much worse than the best DP at **17.25**. Its narrow **41-point band around a precomputed guide**, plus guide-adherence and curvature terms, appears materially less effective than the current best’s broader unconstrained corridor search. This suggests that the winning factor is not “DP” alone, but **DP with enough search freedom and directly evaluator-aligned transition costs**.

  Its code builds:
  - an **81×81 segment-length matrix**,
  - midpoint school/base costs indexed by **j+k** for each step,
  - standard DP and parent tables for exact backtracking.  
  This implementation lets it consider every candidate y-transition efficiently, which is a concrete reason it can jointly optimize distance, noise, and signal better than the heuristic families.

- **The best program’s cost structure is tightly aligned with the observed evaluation priorities.**  
  It uses:
  - `weight_dist = 1.0`

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Add a two-stage DP refinement pass: global corridor first, then a path-centered re-solve with a finer local grid.**  
   Keep the current 81-level full-corridor DP to preserve global search freedom, then build a second DP around the recovered path using a narrower per-waypoint band with finer vertical resolution. This directly extends the strongest observed pattern—global exact optimization first—and should reduce discretization error more effectively than smoothing alone without inheriting the failures of narrow guided-band DP as a primary search.

2. **Replace midpoint-only segment costs with 2–3 interior samples per segment, using a slightly max-biased aggregation for school noise.**  
   For each transition, evaluate school/base cost at positions like 1/4, 1/2, and 3/4 along the segment, then combine them with an average or a weighted average that emphasizes the worst school approach. The best program already showed that transition-level scoring beats pointwise shaping, so richer segment integration is a high-probability way to better capture brief close passes to the school or signal drop regions that midpoint-only scoring can miss.

3. **Use a nonuniform y-grid that is denser near strategically important vertical regions while preserving the same broad corridor.**  
   Keep the bounded corridor logic, but allocate more candidate levels near `y_start`, `y_end`, `sy`, `by`, and along the straight-line interpolation between endpoints, with fewer levels in low-value vertical space. This builds on the success of bounded geometry-aware discretization while improving resolution exactly where the transition costs are most sensitive, potentially improving F3 without sacrificing the full-search advantage of the current DP.

4. **Make transition weights mildly x-dependent, especially increasing base-signal importance in x-regions where signal recovery matters most.**  
   Retain the same DP structure and segment-based objective, but scale `weight_signal` and possibly `weight_noise` as a function of the segment midpoint x-position relative to the base and school. Since recent results show F3 is still the main separator among valid programs, a geometry-adaptive weighting schedule is a targeted way to preserve the current best’s elite F2 while pushing harder on signal loss where it matters most.

5. **Replace unconditional Laplacian smoothing with a short cost-aware local improvement pass that only accepts score-reducing edits.**  
   After DP backtracking, try small local y-adjustments or short-window smoothing proposals for each waypoint, but evaluate the true affected segment costs and keep only moves that lower total path cost. This preserves the current best’s useful “light post-processing” idea while avoiding cases where blind smoothing washes out strategically valuable detours that the DP correctly discovered.
