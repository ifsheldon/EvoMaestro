# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- **The new strongest validated pattern is discrete dynamic programming over a y-grid with midpoint-based segment scoring.**  
  The current best, **Dynamic Programming Grid Path** (**Generation 15, score 17.25**), clearly outperforms the previously best global method, **Modifier-Based Drone Path Smoothing** (**Generation 27, 21.2164**), as well as all newly summarized Gaussian/gradient variants. Its implementation success comes from optimizing the full path jointly across **81 candidate heights per waypoint**, rather than applying independent pointwise deformations. This is the first reported method to push the total score this low while also achieving the best observed combination of **F2=0.46** and **F3=31.12** among the compared correct programs.

- **Jointly balancing distance, school noise, and base signal during path construction works better than sequential post-hoc shaping.**  
  In the current best program, each segment is scored with:
  - weighted Euclidean segment length,
  - school-noise penalty at the segment midpoint,
  - base-signal penalty at the segment midpoint.  
  This direct inclusion of **signal loss during the DP search** appears to be the key difference from the successful Gaussian family, which mostly prioritized school avoidance first and then tried to recover base connectivity afterward. Relative to **Adaptive Gaussian Bend Path** (**22.64**, **F3=33.81**) and **Gaussian Repulsion-Attraction Path Heuristic** (**22.68**, **F3=34.17**), the DP method substantially improves **F3** while still keeping **F2** elite.

- **Restricted but context-aware search ranges are highly effective.**  
  The current best does not search all y-values globally; it expands the y-range around the start/end corridor and only includes school/base y-values when they are within a bounded vertical margin. That bounded expansion plus a fixed **81-level grid** preserves resolution while still allowing meaningful detours. This is a more successful form of geometry awareness than the broad, smooth Gaussian attraction approaches in **Generation 19**, **30**, and **32**, all of which stayed above **22.6** total score.

- **Light post-processing smoothing helps when applied after a globally optimized discrete path.**  
  The current best uses **three rounds of Laplacian smoothing** after backtracking the DP solution. This appears to remove grid artifacts without erasing the optimized geometry. In contrast, programs where smoothness was a primary shaping mechanism—such as **Geometry-Guided Gradient Drone Path** (**60.10**) or the Gaussian families with built-in smooth neighbor blending—did not convert smooth trajectories into strong total scores.

## Ineffective Approaches
- **Pointwise Gaussian shaping remains inferior to full-path optimization, even when carefully tuned.**  
  Several correct programs used variations of straight-line baseline plus Gaussian school repulsion and base attraction:
  - **Adaptive Gaussian Bend Path**: **22.64**
  - **Gaussian Repulsion-Attraction Path Heuristic**: **22.68**
  - **Gaussian Repulsion-Attraction Path Search**: **33.41**  
  These methods kept **F1/F2** reasonable, but evaluator feedback consistently identified **F3 as the dominant weakness**. Their local deformation design did not match the DP method’s ability to globally trade off detour length against base connectivity.

- **Optimization-heavy continuous refinement again underperformed despite better machinery.**  
  **Geometry-Guided Gradient Drone Path** (**60.10**, **F1=1.02**, **F2=1.47**, **F3=40.24**) shows that iterative gradient-style optimization over multiple energy terms can still land far from evaluator-preferred solutions. Even with trust-region clamping, hyperparameter sweeps, and smoothing, it badly trails both the current DP best (**17.25**) and the earlier modifier-based Gaussian best (**21.22**). The added complexity did not solve the core signal-loss problem and also hurt school-noise performance.

- **Broader or more adaptive base attraction alone did not fix the dominant weakness.**  
  **Generation 19** adjusted Gaussian pull strength/spread based on school-base separation, and **Generation 30** searched over attraction amplitudes, sigmas, tail gains, and smoothing factors. Yet both still suffered from high **F3** (**33.81** and **33.62**) relative to the current best’s **31.12**. This reinforces the earlier insight that merely pulling harder toward the base is not enough if the overall path is not optimized end-to-end.

- **Surrogate search over heuristic parameters remained weaker than exact discrete optimization.**  
  **Generation 30** used a deterministic grid search over heuristic parameters and selected by a surrogate objective, but still scored **33.41**. By contrast, the current best directly optimizes a cost very close to the evaluator structure at every segment transition. The gap suggests that exact dynamic programming over a good discretization is much more aligned than tuning smooth heuristic families via surrogate scoring.

## Implementation Insights
- **What makes the current best especially effective is that it optimizes transitions, not just positions.**  
  The DP program precomputes:
  - an **81×81 segment-length matrix** for transitions between candidate y-levels,
  - midpoint costs for school noise and base penalty for each step.  
  This lets it choose each waypoint height in the context of the previous one, effectively controlling both path smoothness and global tradeoffs without requiring explicit curvature penalties. That implementation detail likely explains why it improves both **F2** and **F3** relative to the Gaussian heuristics.

- **Midpoint evaluation is a strong implementation choice.**  
  The current best scores school and base effects at **segment midpoints**, not just at sampled vertices. This likely reduces blind spots where a path segment passes near the school or far from the base between control points. Compared with the pointwise update style in **Generation 19**, **30**, and **32**, midpoint-aware segment scoring is a concrete code-level reason the DP path better matches evaluator geometry.

- **The program’s bounded y-grid construction is an important practical refinement, not just a speed hack.**  
  It includes school/base y-values only when they are within about **200 units** of the start/end corridor, then adds a **±60 margin**. This avoids wasting the fixed 81-grid resolution on extreme vertical regions that are unlikely to help. That is a notable contrast with continuous methods whose broad attraction fields can diffuse effort across irrelevant areas and degrade effective control.

- **Post-DP Laplacian smoothing succeeds because it is applied to an already high-quality path, not used as the main generator.**  
  The current best uses a modest **smooth_alpha = 0.4** for **3 passes**, which likely reduces discretization artifacts while preserving the path’s strategic shape. This is different from methods where smoothing or soft blending was core to the path-generation logic. The results suggest smoothing is most effective as a finishing pass after strong global optimization, not as the central design principle.

  - **Adaptive Gaussian Bend Path (Gen 19): 22.64**

- **The current best improves the previously dominant weakness, F3, more than any other compared method while preserving elite F2.**  
  Its metrics are **F1=1.21, F2=0.46, F3=31.12**. Compared with the earlier best (**F1=1.3371, F2=0.4831, F3=32.8446**), the DP method is better on all three components, with the biggest practical gain in **F3**. That is especially important because prior evaluations repeatedly identified **signal loss as the dominant unresolved term**.

  **Geometry-Guided Gradient Drone Path** had the best listed **F1=1.02**, yet its total score was the worst at **60.10** because **F2** and especially **F3** were poor. However, the current best demonstrates that the next level of improvement came from **changing the optimization structure**, not merely refining Gaussian school/base modifiers within the same family.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Replace the uniform 81-level y-grid with a nonuniform grid that is denser near strategically important y-values.**  
   Keep the same DP structure, but allocate more candidate levels around `y_start`, `y_end`, `sy`, and `by`, with fewer levels in clearly irrelevant vertical regions. This directly extends the current best’s bounded-grid success: it should preserve global optimization while improving resolution exactly where midpoint school/base tradeoffs are most sensitive.

2. **Add a narrow local refinement pass after the first DP solve, using a second DP on a path-centered corridor.**  
   First run the current coarse/global DP exactly as now, then build a tighter y-grid around the recovered path at each waypoint or around each path segment’s local band, and rerun DP within that corridor. This is a natural next step from the winning discrete optimization pattern: keep the strong global structure, then reduce quantization error more effectively than Laplacian smoothing alone.

3. **Upgrade segment scoring from midpoint-only evaluation to small multi-sample quadrature along each segment.**  
   For each transition, score school noise and base penalty at 2–3 interior points (for example 1/4, 1/2, 3/4 of the segment) instead of only at the midpoint, and combine them with a small weighted average or max-biased average. The best program already showed that transition-aware midpoint evaluation beats vertex-only heuristics; a richer segment integral is a very plausible way to further reduce blind spots where segments briefly pass too close to the school or too far from the base.

4. **Make the DP cost weights geometry-adaptive per x-step rather than globally constant.**  
   Keep the same three-term segment objective, but increase school-noise weight in x-regions near the school and increase base-signal weight in x-regions near the base or where the current x is far from `bx`. This preserves the exact end-to-end DP optimization that is currently winning, while making the objective better match the fact that different parts of the route should prioritize different risks.

5. **Replace pure post-hoc Laplacian smoothing with a constrained improvement pass that only accepts score-improving local moves.**  
   After backtracking, try a few local coordinate updates or short window smoothing proposals, but evaluate them using the same segment-based cost and keep only changes that reduce total path cost. The current best already benefits from light smoothing after global optimization; turning that into a cost-aware cleanup step is more aligned with the successful DP logic and less likely to wash out useful detours.
