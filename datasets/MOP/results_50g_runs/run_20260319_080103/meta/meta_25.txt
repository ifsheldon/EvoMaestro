# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- **The new best confirmed pattern is a modifier-based version of the same core winning heuristic: straight-line baseline + strong localized school repulsion + sequential base recovery.**  
  The current best, **Modifier-Based Drone Path Smoothing** (**Generation 27, score 21.2164**), improves on the previously best-reported **Gaussian School Avoidance with Base Attraction** (**22.67**) by keeping the same high-level structure but refining the base-attraction stage. Its metrics—**F1=1.3371, F2=0.4831, F3=32.8446**—show that this family remains decisively stronger than the newer alternatives such as **Generation 26** (**31.15**), **Generation 22** (**33.81**), **Generation 23** (**36.59**), and **Generation 24** (**39.06**).

- **Very strong, sign-based school avoidance continues to be the most reliable source of low total score.**  
  In the current best, the school modifier uses a fixed-amplitude vertical push:
  `direction = -1 if self.sy > y else 1`
  `return y + direction * self.push_distance * weight`  
  with **push_distance=50.0** and Gaussian x-localization (**width=800.0**). This produces the best observed **F2=0.4831**, slightly better than the prior best family’s roughly **0.49**, and far better than **Generation 26** (**0.71**), **Generation 22** (**0.8466**), **Generation 23** (**0.91**), and **Generation 24** (**1.01**). Across evaluations, aggressive localized school avoidance remains the clearest differentiator.

- **Sequential “avoid first, then recover toward base” remains the strongest validated update order, especially when the base pull is modulated rather than uniform.**  
  The current best improves over simpler sequential Gaussian methods by applying base attraction *after* school deformation and scaling that attraction using school proximity:
  `pull = pull_ratio * (1.0 - conflict_soften * w_s)`
  then
  `pull *= (1.0 + recovery_boost * (1.0 - w_s))`  
  This conflict-soften/recovery-boost design appears to be the key implementation change behind the jump from the older best (**22.67**) to **21.22**, while maintaining a similarly excellent **F2** and slightly improving **F3** relative to many later programs.

- **Lightweight endpoint-aware blending helps preserve the benefits of strong deformation without collapsing into overly stylized global shaping.**  
  The current best uses a nonzero-floor window,
  `window = 0.35 + 0.65 * center_emphasis`,
  to blend modified y-values back toward the straight line. This is materially different from full-window suppression approaches seen in **Sequential Gaussian Path Shaping** (**39.06**) and **Sequential Gaussian Bend Path** (**31.15**), where sinusoidal tapering kept F1/F2 controlled but did not convert into competitive total score. The current best’s blend retains strong middle-path shaping while keeping endpoints stable.

## Ineffective Approaches
- **Optimization-heavy formulations still underperform the simple sequential Gaussian/modifier heuristic.**  
  **Geometry-Aware Potential Field Path** (**Generation 22, 33.8087**) used 180 iterations of gradient descent over a weighted objective with path length, avoidance, attraction, and smoothness terms, yet scored much worse than the current best’s **21.2164**. The same pattern was already seen in prior global results, where search-heavy or gradient-based systems trailed the simpler Gaussian family. The evaluation feedback repeatedly identified **F3 as the remaining weakness**, indicating the extra machinery did not solve the dominant bottleneck.

- **Symmetric or staged smooth shaping without strong asymmetric school-vs-base handling produces much weaker totals.**  
  **Gaussian Repulsion-Attraction Path** (**36.59**) and **Sequential Gaussian Path Shaping** (**39.06**) both used deterministic, smooth Gaussian adjustments and achieved respectable **F1/F2**, but they were not competitive overall because their base recovery was too generic and **F3 stayed dominant**. Compared with the current best’s school-aware base modulation, these methods lacked the code-level asymmetry that earlier insights had already identified as important.

- **Sinusoidal/windowed deformation alone does not create a winning tradeoff.**  
  **Generation 24** and **Generation 26** both used `sin(pi*t)` endpoint tapering and smooth Gaussian bending, but still landed at **39.06** and **31.15** respectively. Even though **Generation 26** had decent **F2=0.71**, it remained far behind the current best’s **0.4831** and did not gain enough on **F3** to compensate. This reinforces the prior insight that stylized smoothness is weaker than direct geometry-aware Gaussian deformation.

- **Base attraction that is merely broad or stronger in isolation is not enough if it is not coordinated with school avoidance.**  
  Several correct programs explicitly tried to improve base pull—**Generation 23** with two attraction passes, **Generation 24** with broad plus tight recovery, and **Generation 26** with broader moderate attraction after repulsion—but all still suffered from evaluator feedback that **signal loss remained the dominant contributor**. The current best’s improvement came not from simply pulling harder, but from making base pull depend on conflict with school avoidance.

## Implementation Insights
- **What makes the current best especially effective is the precise code-level decoupling of the school and base behaviors.**  
  The school term is a **fixed-magnitude, sign-based displacement** localized only by x-distance from the school, while the base term is a **gap-closing interpolation toward `base_y`** localized by x-distance from the base. This preserves the asymmetry already highlighted in earlier insights, but the current best further refines it by reducing base pull where school influence is strong and boosting it elsewhere. That extra modulation appears to be the major implementation improvement over the prior best.

- **The current best’s base modifier is not a raw Gaussian pull; it is a school-aware gain schedule.**  
  In `BaseAttractionModifier.apply`, the effective pull is:
  - softened near the school via `1 - conflict_soften * w_s`
  - boosted away from the school via `1 + recovery_boost * (1 - w_s)`
  - capped at `1.0`  
  This is a more targeted version of the earlier “recover toward base after avoidance” idea. Relative to the simpler sequential Gaussian programs, this likely explains why **Generation 27** keeps elite **F2** while also posting one of the best **F3** values among correct high-performing methods.

- **Uniform x-sampling with independent per-point y updates remains the dominant implementation template.**  
  The current best, like the earlier successful Gaussian heuristics, constructs interior points from a straight-line interpolation and then modifies only y-values pointwise. It does not use control-point search, path-level optimization, curvature penalties, or iterative refinement. The newer worse-performing methods—especially **Generation 22’s** gradient descent—again show that global optimization complexity did not translate into better evaluator-aligned geometry.

- **A blend-back-to-baseline step works best when it preserves a substantial fraction of the deformation even near endpoints.**  
  The current best’s window has a floor of **0.35**, unlike stronger endpoint suppression in sinusoidal-window methods. That means the optimizer effect is never fully turned off. This implementation detail is consistent with its strong empirical results: **F1 stays acceptable at 1.3371**, while **F2** remains best-in-class and **F3=32.8446** is competitive with or better than all newly summarized programs.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Split the school and base x-kernels more aggressively, keeping the school kernel narrow and the base kernel broad.**  
   Replace the shared `school_width=800.0` / `width=2600.0` pattern with explicitly tunable `school_width` and `base_width`, and mutate in the direction of `school_width` slightly smaller and `base_width` slightly larger. This preserves the winning “sharp local avoidance + broad later recovery” structure and is strongly supported by the current best’s success with localized F2 suppression and staged F3 recovery.

2. **Make school push amplitude mildly geometry-aware, but keep the sign-based fixed-force behavior as the backbone.**  
   Instead of always using `push_distance=50.0`, use something like `amp = A0 + A1 * exp(-((y_line - school_y) ** 2) / tau)` or a clipped vertical-proximity boost, then apply the same sign rule. The evidence says the sign-based repulsion itself is the key win, so the mutation should only strengthen it when the straight line truly conflicts with the school and avoid turning it into a fully smooth proportional field.

3. **Upgrade base attraction from school-aware to conflict-aware using both school influence and current displacement from the base.**  
   Keep base attraction second, but compute `pull` from both `w_s` and the remaining base gap, e.g. stronger pull when `abs(base_y - y)` is large and `w_s` is small, weaker pull when school influence is high. This directly extends the best program’s most successful innovation—modulated recovery—while targeting F3 more precisely than a uniform post-school interpolation.

4. **Add a small second recovery pass near the base, but make it narrower and weaker than the main base modifier.**  
   After the current `BaseAttractionModifier`, apply a second modifier with a tighter `base_width_post` and smaller `pull_ratio_post` so that only points close in x to the base get an extra nudge toward `base_y`. Prior results suggest generic extra shaping is not useful, but a localized cleanup pass is consistent with the successful sequential design and may trim F3 without sacrificing the elite F2.

5. **Mutate the endpoint blending window, but keep a nonzero floor and avoid full tapering.**  
   The current `window = 0.35 + 0.65 * center_emphasis` is already better than stronger endpoint suppression, so test nearby variants such as a slightly lower or higher floor, or a flatter center-emphasis curve like `1 - abs(2t-1) ** p` with tuned `p`. This is promising because the best program’s blend-back step is clearly helping preserve the strong deformation while keeping F1 acceptable, and small changes here could improve the F1/F3 tradeoff without disturbing the core heuristic.
