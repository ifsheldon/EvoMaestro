# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- **The current best remains the strongest confirmed pattern: straight-line baseline + fixed-amplitude Gaussian school repulsion + sequential Gaussian base pull.**  
  The current best program, **Gaussian School Avoidance with Base Attraction**, still leads at **22.67** with **F1=1.36, F2=0.49, F3=33.99**. Its key implementation choice is the two-stage update:
  `y += push_dir * 35.0 * w_s` followed by `y += (y_b - y) * w_b`.  
  Compared with later correct programs such as **Gaussian-Sinusoidal Drone Path Deformation** (**23.86**) and **Gaussian Repulsion-Attraction Path Search** (**35.20**), this simpler asymmetric formulation continues to produce the best overall tradeoff.

- **Strong, sign-based school avoidance is consistently the main source of score gains.**  
  The current best achieves by far the lowest reported **F2=0.49**, outperforming **Generation 20** (**F2=0.5352**, score **23.86**), **Generation 18** (**F2=0.8657**, score **35.20**), **Generation 17** (**F2=1.06**, score **41.14**), and **Generation 21** (**F2=0.97**, score **38.57**). This reinforces the prior insight that a **fixed vertical displacement localized by Gaussian x-weighting** is more effective than proportional or optimizer-balanced school terms.

- **Simple geometry-aware Gaussian deformation still beats more elaborate variants, even when those variants improve one metric.**  
  **Generation 20: Gaussian-Sinusoidal Drone Path Deformation** is the closest new competitor at **23.8582**, with strong **F2=0.5352** and similar **F3=33.0640**. Its success supports the same family of methods: independent x-sampled y deformation from a straight line, localized school repulsion, and base attraction. However, it still trails the current best because the best program’s stronger school-avoidance pattern yields a better total balance despite a slightly worse F1/F3 mix.

- **Sequential asymmetric handling of school then base remains the most validated design across generations.**  
  **Generation 17** also used a sequential pattern—school repulsion followed by base attraction—and passed validation with **41.14**, but its sinusoidal windowing and fixed hyperparameters were much weaker overall. **Generation 18** similarly combined repulsion and attraction with a search over parameters, reaching **35.20**. Across these results, the successful commonality is not the extra tuning machinery, but the **ordered “avoid school first, then recover toward base” structure**, which the current best implements in the most direct way.

## Ineffective Approaches
- **Safety wrappers and control-point clamping do not rescue a weak path formulation.**  
  **Clamped Control-Point Wrapper** enforced x-ordering and spacing constraints and added robust exception handling, yet it remained **incorrect**, failed validation, and had a combined score of **0.0**. This confirms that defensive control-point logic and crash protection improve robustness only superficially; they did not contribute to evaluator-aligned path quality.

- **More sophisticated search and optimization layers have not translated into better scores than the simple Gaussian heuristic.**  
  **Generation 18: Gaussian Repulsion-Attraction Path Search** added deterministic grid search, a multi-term surrogate, tail pull, smoothing, and final clamping, but only reached **35.20**. **Generation 21: Potential-Field Gradient Drone Path** used iterative gradient descent with smoothing and clipping and scored **38.57**. In both cases, evaluator feedback explicitly pointed to **F3 remaining dominant**, so the extra machinery did not outperform the current best’s direct shaping.

- **Sinusoidal or windowed shaping remains inferior when compared with direct Gaussian geometry alignment.**  
  **Generation 17: Sequential Potential Field Path Bending** used sinusoidal-windowed Gaussian repulsion and sequential attraction yet scored only **41.14**, with **F3=34.21** still dominating. This is consistent with the earlier poor performance of sinusoidal-arch families and supports the prior conclusion that stylized smooth shaping is weaker than direct localized Gaussian deformation.

- **Dynamic width/base-variance adjustments can help, but do not surpass the fixed strong school-push template.**  
  **Generation 20** introduced a **dynamic-width base attraction** tied to school-base separation and performed well at **23.86**, but still did not beat the current best. This suggests that extra adaptivity in the base term is less impactful than the current best’s very strong school-avoidance mechanism, especially since the best score advantage is driven mainly by **F2** rather than **F3**.

## Implementation Insights
- **What makes the current best especially effective is the exact code-level asymmetry between the school and base terms.**  
  The school effect is **constant-amplitude and sign-based**:
  `push_dir = -1 if y_s > y_line else 1`
  `y += push_dir * 35.0 * w_s`  
  while the base effect is **proportional to the remaining gap**:
  `y += (y_b - y) * w_b`  
  This differs from formulations where both influences are treated symmetrically or both are proportional to geometry, and the performance data shows this asymmetry is highly effective.

- **The current best benefits from applying the base attraction to the already-deformed path, not the baseline.**  
  Because `w_b` is applied after school avoidance, the base term acts as a correction on the repelled trajectory. This same sequential idea appears in **Generation 17** and **Generation 18**, but the current best’s much shorter implementation achieves the strongest result, suggesting that the **update order itself** is more important than added tuning layers.

- **Uniform x-sampling with per-point independent y computation remains the strongest implementation template.**  
  The current best computes each interior y directly from `x`, `y_line`, and two Gaussian weights, with no global optimizer, no smoothing pass, and no curvature penalty. The new evaluated correct programs that also stay close to this template—especially **Generation 20**—remain the most competitive. By contrast, search-heavy (**Generation 18**) and gradient-based (**Generation 21**) methods underperform.

- **The latest evaluations reinforce that stronger school avoidance can be worth a modest F1 penalty.**  
  The current best has **F1=1.36**, worse than **Generation 17** (**1.13**) and **Generation 21** (**1.12**), yet its total score is much better because its **F2=0.49** is dramatically lower. This matches the prior global insight that the evaluator rewards the specific path geometry induced by aggressive localized school avoidance more than it penalizes moderate distance inflation.

## Performance Analysis
- **The current best still clearly outperforms all newly evaluated correct programs.**  
  Score comparison: **22.67** (current best) vs **23.86** (**Generation 20**) vs **35.20** (**Generation 18**) vs **38.57** (**Generation 21**) vs **41.14** (**Generation 17**). The gap to the nearest new competitor is about **1.19**, while the gap to the search/optimizer-style methods is much larger, confirming that the best-known approach remains the simple asymmetric Gaussian heuristic.

- **The main differentiator is still F2, not F3.**  
  The current best does **not** have the best signal-loss term among all compared methods: **Generation 20** has slightly better **F3=33.0640** vs **33.9856** for the best. But the current best wins overall because its **F2=0.4900** is materially better than **0.5352** in Generation 20 and far better than the others. This strengthens the earlier conclusion that the evaluator favors a tradeoff with exceptionally low school-noise cost even if F3 stays in the low-30s.

- **Recent correct programs all confirm the same bottleneck: F3 remains dominant once correctness is achieved.**  
  The new results show **F3=34.21** for **Generation 17**, **32.84** for **Generation 18**, **33.06** for **Generation 20**, and **35.49** for **Generation 21**. Evaluator feedback for each explicitly notes that signal loss is still the dominant weakness. So across multiple implementation families, the major remaining variation in total score comes from how much they can improve school avoidance without letting F3 become too costly.

- **Complexity is negatively correlated with score quality in these evaluations.**  
  The simplest strong methods remain best: the current best’s compact two-Gaussian sequential deformation scores **22.67**, while more engineered versions score worse: **23.86** for dynamic variance, **35.20** for surrogate-guided search with smoothing/clamping, and **38.57** for iterative gradient descent. This continues the long-running pattern from earlier evaluations that **direct evaluator-aligned Gaussian shaping** is more effective than optimization-heavy or stylized alternatives.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Keep the exact two-stage update order, but split the Gaussian widths into `sigma_s2` and `sigma_b2` and bias them as `sigma_s2 < sigma_b2`.**  
   Implement `w_s = exp(-((x - x_s)**2) / sigma_s2)` and `w_b = exp(-((x - x_b)**2) / sigma_b2)` instead of sharing `400.0`, with mutations centered around a narrower school kernel and a broader base kernel. This directly preserves the strongest validated pattern—localized fixed school push followed by recovery toward base—while giving the base attraction more spatial room to reduce F3 without diluting the F2 advantage.

2. **Make the school-push amplitude geometry-aware while preserving its sign-based, mostly fixed-force character.**  
   Replace the constant `35.0` with something like `amp_s = A0 + A1 * exp(-((y_line - y_s)**2) / tau)` or a clipped function of vertical school proximity, then use `y += push_dir * amp_s * w_s`. The evidence suggests the sign-based repulsion is the key win, so the safest mutation is not to make it proportional everywhere, but to keep it strong near true school conflict and slightly weaker when the straight line is already far from the school.

3. **Bias the repulsion direction using both school side and base side, but only in conflict cases.**  
   Start from the current `push_dir = -1 if y_s > y_line else 1`, then add a conditional override when the base lies on the same side as the repulsion or when `abs(y_b - y_line)` is small, e.g. choose the push sign that both avoids the school and reduces later correction toward the base. This is a targeted extension of the best program’s asymmetry and may improve F3/F1 by reducing how much the second stage must “undo” the school deformation.

4. **Condition the base-attraction strength on school influence so the school dip is preserved near `x_s` but recovery is stronger elsewhere.**  
   For example, use `base_scale = 1 - alpha * w_s` or `base_scale = beta + (1 - beta) * (1 - w_s)` and then apply `y += base_scale * (y_b - y) * w_b`. This follows the proven sequential structure while addressing the main observed tradeoff: the best program wins on F2, so mutations should protect that local avoidance shape instead of letting base attraction wash it out where school pressure is strongest.

5. **Add a small, narrow post-recovery pull centered at the base after the current main update.**  
   After `y += (y_b - y) * w_b`, try `y += alpha_post * (y_b - y) * exp(-((x - x_b)**2) / sigma_b2_post)` with `alpha_post` small and `sigma_b2_post` tighter than the main base kernel.
