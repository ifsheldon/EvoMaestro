## Successful Algorithmic Patterns
- **The current best is still the simple two-stage independent Gaussian shaper, and its exact sequencing remains the strongest observed pattern.**  
  **Gaussian Base-Attract School-Avoid Path (Gen 34)** remains the leader at **16.72** with **F1 = 1.45, F2 = 0.35, F3 = 33.03**. Its implementation applies a **broad base attraction first**  
  `y += (by - y) * w_b` with `sigma_b2 = 1200.0`,  
  then a **sharper school repulsion second**  
  `y += global_push_dir * 40.0 * w_s` with `sigma_s2 = 450.0`.  
  This exact uncoupled, per-point structure continues to outperform more elaborate variants.

- **A single globally consistent school-avoidance direction is still the clearest high-value feature for elite F2.**  
  Gen 34 determines `global_push_dir` from the **base-adjusted projected height at the school x-position**, not from the raw line:  
  `y_at_sx = y_line_sx + (by - y_line_sx) * w_b_sx`, then  
  `global_push_dir = -1.0 if sy > y_at_sx else 1.0`.  
  This remains associated with the best-known **F2 = 0.35**, outperforming later correct programs such as **Gen 45 (F2 = 0.62)**, **Gen 43 (0.70)**, **Gen 28 (0.68)**, **Gen 48 (1.17)**, and **Gen 50 (1.54)**.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Keep the exact Gen-34 structure, but make the school-push amplitude a tiny clearance-aware scalar instead of a fixed `40.0`.**  
   Compute `clearance = abs(sy - y_at_sx)` using the same base-adjusted `y_at_sx`, then set `push_amp = clamp(36.0 + k * max(0.0, c0 - clearance), lo, hi)` with a narrow range such as `36–46`. This preserves the winning pointwise, two-stage geometry and one global dodge side, while only strengthening the push in the cases where the current sign decision predicts a close school pass.

2. **Retain one global dodge direction, but choose it using a tiny multi-sample comparison around `sx` rather than a single-point test.**  
   Evaluate the Gen-34 path formula at 3–7 `x` samples near the school for both `global_push_dir = +1` and `-1`, then pick the sign with the larger minimum vertical separation from the school. This is strongly aligned with the evidence that a single globally consistent avoidance side is crucial, but it makes the most important decision slightly more robust without introducing smoothing or iterative optimization.

3. **Add a very small asymmetric post-school tail to the school Gaussian so the path stays on the safe side slightly longer after passing `sx`.**  
   For example, keep the main repulsion term unchanged for `x <= sx`, but multiply it by `1.05–1.20` for `x > sx`, or add a second weaker Gaussian like `global_push_dir * 6–12 * exp(-((x-(sx+d))**2)/sigma_tail2)`. This follows the prior recommendation and is promising because it preserves the localized school-clearance mechanism that drives elite F2, while potentially improving downstream geometry and signal loss.

4. **Introduce only mild left/right asymmetry in the broad base-attraction field, while preserving base-first then school-second sequencing.**  
   Replace `sigma_b2` with `sigma_b2_left` and `sigma_b2_right`, or use slightly different base-pull strengths before and after `bx`, such as a broader/weaker attraction on approach and a narrower/stronger recovery after passing the base.
