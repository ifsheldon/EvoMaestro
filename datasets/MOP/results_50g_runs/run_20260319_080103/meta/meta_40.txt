# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- **The new current best is an extremely simple two-field Gaussian path, and its main strength is an exceptional F2 result.**  
  **Gaussian Base-Attract School-Avoid Path (Gen 34)** is now the best observed program at **16.72**, improving on the previous best **Dynamic Programming Grid Path (Gen 15, 17.25)**. Its implementation is unusually minimal: start from the straight-line interpolation, apply a **broad Gaussian attraction toward the base first**, then a **sharper Gaussian repulsion from the school**, while enforcing a **single global dodge direction** for all points. That combination produced **F2 = 0.35**, clearly better than Gen 15’s **0.46**, and is the most concrete source of the new best total score.

- **A fixed, globally consistent school-avoidance direction appears better than locally varying avoidance.**  
  In **Gen 34**, the dodge sign is chosen once by comparing the school’s y-position to the baseline/base-influenced path near the school, then reused across the whole trajectory. This likely avoids self-canceling bends and helps explain why it beat more complex Gaussian variants such as **Gaussian Biased Drone Path (Gen 37, 24.67, F2=0.58)** and **Hybrid Gaussian Drone Path Heuristic (Gen 39, 39.13, F2=1.00)**.

- **Applying base attraction before school repulsion is a successful ordering change.**  
  The current best explicitly “**bends toward base first**” and only then applies school repulsion “to guarantee F2 safety.” That ordering is more effective than the broader multi-stage Gaussian families summarized earlier, which often mixed attraction/repulsion/smoothing but still lagged badly on total score, such as **Gen 33 (29.77)** and **Gen 29 (31.31)**.

- **Direct shaping can outperform global search if its parameterization aligns tightly with evaluator priorities.**  
  Earlier evidence favored full-grid DP, but **Gen 34** shows a counterexample: a very low-parameter continuous heuristic can win if it strongly suppresses school exposure. Its **16.72** score beats both the prior best **Gen 15 (17.25)** and all later sophisticated methods like **Bezier Pattern Search (Gen 38, 24.21)** and **Two-Stage Corridor DP (Gen 40, 37.36)**.

## Ineffective Approaches
- **More complex Gaussian heuristics consistently underperformed the new best because they worsened F3 and often also F2.**  
  Compared with **Gen 34 (16.72, F2=0.35, F3=33.03)**, the more elaborate **Gen 37** added conflict-aware attraction plus two-pass neighbor smoothing but still scored **24.67** with **F3=35.07**. **Gen 39** added deterministic grid search over amplitudes/sigmas/pulls/tail gains and still scored a much worse **39.13**. Extra stages and tuning did not translate into evaluator-aligned gains.

- **Search-heavy continuous parameter optimization did not beat a clean fixed-form path.**  
  **Heuristic Bezier Drone Path (Gen 38)** used candidate grid search, local refinement, inverse sampling, and post-smoothing, yet scored **24.21**. Its **F1=1.15** was better than Gen 34’s **1.45**, but **F2=0.66** remained much worse and its overall advantage on geometric efficiency did not compensate. This suggests that lower path length alone was less decisive than robust school avoidance.

- **Restricted or over-regularized DP remains weaker than either the old full-grid DP or the new simple Gaussian best.**  
  **Two-Stage Corridor DP Path Planner (Gen 40)** scored **37.36** despite strong **F1=1.13**. Its narrow refinement corridor, prior toward a handcrafted reference path, curvature-state penalty, and smoothing reduced flexibility too much. - **Signal-loss-focused complexity often failed to improve actual signal-loss outcomes.**

Even when a method was designed to “pull toward base” more intelligently, those changes usually did not beat the new best’s simpler broad base-attraction term.

## Implementation Insights
- **The current best works through a very specific asymmetric Gaussian design: broad base pull, narrow school push, and no iterative refinement.**  
  In code, **`sigma_b2 = 1200.0`** and **`sigma_s2 = 450.0`** give the base influence a wider x-range than the school influence. Each point is computed independently from the line baseline, then adjusted by  
  `y += (by - y) * w_b`  
  followed by  
  `y += global_push_dir * 40.0 * w_s`.  
  This simple structure appears to be enough to generate a stable, evaluator-friendly tradeoff without smoothing, optimization loops, or discrete search.

- **The global dodge-direction calculation is a key implementation detail, not just a conceptual choice.**  
  The program estimates the path height at the school x-position after partial base attraction, then chooses  
  `global_push_dir = -1.0 if sy > y_at_sx else 1.0`.  
  That means all intermediate points avoid the school on the same side. Relative to methods that rely on local forces or candidate search, this likely prevents oscillatory crossing behavior and is strongly supported by the best observed **F2=0.35**.

- **The current best is effective despite not using the transition-level midpoint scoring that previously defined the strongest DP approach.**  
  Earlier, **Gen 15** led through full-path joint optimization with midpoint segment costs and an **81-level y-grid**. Now **Gen 34** beats it without any DP table, parent reconstruction, or smoothing passes. The important implementation insight is that evaluator alignment can also come from a hand-shaped path family whose geometry already encodes the desired tradeoff.

- **Many heavier implementations improved F1 modestly but lost evaluator alignment elsewhere.**  
  For example, **Gen 38** reached **F1=1.1548** and **Gen 40** reached **F1=1.13**, both clearly shorter than **Gen 34’s 1.45**, yet their totals were much worse. The code-level implication is that sophisticated sampling, smoothing, or curvature penalties can improve geometric neatness while still hurting the more important school/base balance reflected in total score.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Keep the same two-stage Gaussian shape, but make the school push amplitude depend on the base-adjusted clearance at the school x-position.**  
   Instead of a fixed `40.0`, compute a stronger or weaker push from how close `y_at_sx` is to `sy` after the base-attraction step, then clamp it to a narrow range like `32–52`. This directly extends the current best’s winning structure—base pull first, single global dodge second—while targeting even lower F2 without introducing the search-heavy complexity that hurt later Gaussian variants.

2. **Add a small asymmetric “tail” to the school avoidance so the path stays on the safe side slightly longer after passing the school.**  
   Keep the current Gaussian centered at `sx`, but multiply it by a factor that is modestly larger for `x > sx` than for `x < sx`, or add a second weaker Gaussian centered just beyond the school. This is a minimal mutation of the best design that may preserve its elite F2 while improving F3 by avoiding an immediate snap-back toward the baseline/base too early.

3. **Let the base attraction use different widths before and after the base x-position.**  
   Replace the single `sigma_b2 = 1200.0` with `sigma_b2_left` and `sigma_b2_right`, so the path can begin bending toward the base broadly from one side but relax faster or slower on the other side. The best program already benefits from broad base attraction, and this asymmetric extension is a lightweight way to improve the school/base tradeoff without abandoning the successful independent-per-point formulation.

4. **Refine the global dodge direction rule by comparing both candidate sides and choosing the one with the larger estimated school clearance near `sx`.**  
   Instead of only using `sy > y_at_sx`, explicitly estimate a small neighborhood around the school for both “push up” and “push down” candidate paths, then pick the direction with better minimum separation. This preserves the highly successful idea of one globally consistent avoidance side, but makes the side selection more robust in cases where a single-point comparison is too crude.

5. **Apply a very short cost-aware local adjustment pass after constructing the Gaussian path, using only accepted edits on a few waypoints near the school and base.**  
   For example, try tiny `±δ` y-perturbations on the 3–7 points closest in x to `sx` and `bx`, and keep only changes that improve a simple proxy such as increased school clearance with limited path-length growth and preserved base pull. This follows the evidence that direct shaping is strong, while avoiding the broad smoothing and heavy optimization passes that repeatedly degraded alignment with the evaluator.
