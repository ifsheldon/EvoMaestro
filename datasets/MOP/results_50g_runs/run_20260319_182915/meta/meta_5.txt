# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- **Iterative active-contour optimization was the biggest breakthrough.** The current best program, **Gradient-Based Drone Path Optimizer** (**score 14.19**), improved dramatically over all earlier heuristics by starting from a straight line and repeatedly updating intermediate y-values with a combined gradient for **smoothness + school repulsion + base attraction**. This outperformed:
  - **Sinusoidal Gaussian Drone Path Heuristic**: **43.31**
  - **Gaussian Push Polyline Heuristic**: **32.31**
  - **Gaussian Multi-Objective Path Search**: **80.07**
  - **Straight-Line Y Interpolation**: **96.23**
- **Strong school-avoidance shaping consistently helps when kept smooth.** The best program achieved **F2 = 0.32**, far better than the straight-line baseline’s **F2 = 2.23**, and also better than the other Gaussian/sinusoidal methods (**F2 = 1.06, 1.94, 0.70**). This suggests that explicit localized repulsion around the school is a reliably effective pattern when integrated into a smooth path model.
- **Anchoring optimization to a straight-line initialization preserves reasonable distance while enabling objective tradeoffs.** The best program still keeps **F1 = 1.45**, which is only modestly above the straight-line and search-heavy methods, while massively lowering total score. Multiple successful programs share this pattern: begin with the straight baseline, then add controlled deformations rather than constructing a path from scratch.
- **Localized base influence works better than broad global bending alone.** The current best uses an x-localized Gaussian base weighting in its attraction term. Although **F3 = 30.17** is still the dominant cost, it is materially better than the other nontrivial methods:
  - **Sinusoidal Gaussian Drone Path Heuristic**: **F3 = 36.69**
  - **Gaussian Push Polyline Heuristic**: **F3 = 35.69**
  - **Gaussian Multi-Objective Path Search**: **F3 = 41.14**
  - **Straight-Line baseline**: **F3 = 43.20**

## Ineffective Approaches
- **Ignoring `school` and `base` entirely produces good distance but very poor overall multi-objective performance.** The **Straight-Line Y Interpolation** baseline had excellent simplicity and **F1 = 1.00**, but its total score was the worst among valid programs at **96.23**, with especially poor **F3 = 43.20** and weak **F2 = 2.23**.
- **Fixed-form heuristic offsets without adaptive refinement underperform.** Both the **Sinusoidal Gaussian Drone Path Heuristic** (**43.31**) and **Gaussian Push Polyline Heuristic** (**32.31**) used smooth Gaussian-based deformations, but their fixed-amplitude/path-shape design left **signal loss dominating** (**F3 = 36.69** and **35.69**). They improved over the baseline but were far worse than the iterative optimizer.
- **Proxy-scored parameter search did not translate into strong real evaluation performance.** The **Gaussian Multi-Objective Path Search** used coarse search, local refinement, proxy objectives, and smoothing, yet still scored **80.07** with **F3 = 41.14**. This indicates that a more elaborate search framework was not effective when its internal proxy objective failed to align with the grader’s true score landscape.
- **Global bends alone were not enough to solve the base-signal tradeoff.** Programs relying on sinusoidal/global shaping plus Gaussian influences improved school avoidance somewhat, but evaluation feedback repeatedly identified **signal loss** as the remaining weakness, showing that broad smooth detours did not target the base objective effectively enough.

## Implementation Insights
- **The current best program’s effectiveness comes from direct pointwise optimization of y-values with fixed x-spacing.** This keeps the search space simple and valid while allowing each intermediate point to respond to local geometry. Its in-place **Gauss-Seidel-style updates** likely help the path settle faster and more coherently than one-shot offset formulas.
- **The best implementation combines three gradients that map cleanly to the three objectives.**
  - `grad_smooth` encourages short, low-curvature paths and helps control **F1**
  - `grad_school` uses Gaussian repulsion around the school and strongly improves **F2**
  - `grad_base` attracts the path toward the base’s y-level near the base’s x-region and lowers **F3**
  This decomposition is more directly tied to the evaluation objectives than the more indirect proxy-scoring approach in **Gaussian Multi-Objective Path Search**.
- **Stability mechanisms appear important to correctness and usable optimization behavior.** The current best includes **gradient clipping** and a symmetry-breaking safeguard when `dy_school` is near zero. These details likely prevent numerical issues and avoid degenerate updates, enabling 500 iterations to remain stable under large repulsion strength (`beta = 5000.0`).
- **Smoothness control is a recurring requirement across successful methods, but in the best program it is enforced dynamically rather than cosmetically.** Earlier programs used endpoint-zero envelopes, sinusoidal tapering, and post-hoc smoothing passes; the current best instead embeds smoothness directly in the optimization energy, which better preserves path quality while still allowing strong local avoidance/attraction effects.

## Performance Analysis
- **The current best program is a large step ahead of all prior valid programs.** Its **MOP score of 14.19** is:
  - ~**56% better** than **Gaussian Push Polyline Heuristic** (**32.31**)
  - ~**67% better** than **Sinusoidal Gaussian Drone Path Heuristic** (**43.31**)
  - ~**82% better** than **Gaussian Multi-Objective Path Search** (**80.07**)
  - ~**85% better** than the **Straight-Line baseline** (**96.23**)
- **The dominant trend is that lowering F3 drives most of the total-score improvement.** Across programs, **F1** stays in a relatively narrow band (**1.00–1.45**) and **F2** can be pushed quite low, but **F3** varies widely and tracks total score most strongly:
  - Baseline: **F3 = 43.20**, score **96.23**
  - Search heuristic: **F3 = 41.14**, score **80.07**
  - Smooth Gaussian heuristic: **F3 = 36.69**, score **43.31**
  - Gaussian push heuristic: **F3 = 35.69**, score **32.31**
  - Current best: **F3 = 30.17**, score **14.19**
- **A slight sacrifice in path length is worthwhile when it substantially reduces school noise and signal loss.** The best program has the worst **F1** among the listed valid solutions (**1.45** vs. **1.00–1.29** for several others), yet its total score is by far the best because the reductions in **F2** and especially **F3** more than compensate.
- **There is a clear progression from static geometry heuristics to direct optimization.** Simple straight-line interpolation was shortest but ineffective overall; handcrafted Gaussian/sinusoidal deformations improved results; search over handcrafted parameters still lagged; the strongest result came from **iteratively optimizing the path itself** under explicit multi-term forces. This is the clearest pattern in the evaluated results.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Upgrade the optimizer from fixed-step gradient descent to a scheduled or adaptive update rule.** Keep the same pointwise active-contour formulation, but use a larger learning rate early and decay it over iterations, or normalize each term and scale updates by recent gradient magnitude. This directly extends the current best program’s strongest idea while addressing a likely limitation: fixed `learning_rate=0.1` and fixed 500 iterations may be leaving F3 improvements on the table or over-updating once the path is mostly settled.

2. **Make the base-attraction term depend on both x-locality and estimated signal urgency, not just pull toward `y_base`.** Concretely, try a stronger and sharper attraction near the base’s x-region (`sigma_base` annealing or piecewise weights), and optionally scale `gamma` upward only for points whose current y is still far from `y_base`. This is highly evidence-based because F3 remains the dominant cost, and the current best already shows that localized base influence is one of the few changes that materially improves that objective.

3. **Add a second-order smoothness/bending penalty to control curvature separately from simple neighbor averaging.** Instead of only using `2*(2*y_i - y_{i-1} - y_{i+1})`, introduce a curvature term such as `(y_{i-1} - 2*y_i + y_{i+1})` or even a discretized bi-Laplacian penalty, with modest weight. This preserves the successful “smooth but adaptive” contour framework while allowing stronger school avoidance and base attraction without paying as much in F1 from jagged local deformations.

4. **Use multi-phase optimization: first prioritize school clearance, then gradually shift emphasis toward base alignment.** For example, run early iterations with high `beta` and low `gamma` to push the path safely away from the school, then reduce `beta` and increase `gamma` so the already-safe path is drawn toward the base region. This builds directly on the current decomposition of gradients and targets the observed bottleneck that F2 is already very good while F3 still dominates.

5. **Allow limited x-coordinate adaptation for points near the school/base instead of fixing all x positions uniformly.** Keep the path ordered and mostly straight in x, but permit small local horizontal shifts with regularization so points can “linger” near favorable base regions or bypass the school more efficiently. The current best succeeded by simplifying the search space with fixed x-spacing, but a tightly constrained extension here could unlock better F3/F2 tradeoffs without abandoning the proven active-contour approach.
