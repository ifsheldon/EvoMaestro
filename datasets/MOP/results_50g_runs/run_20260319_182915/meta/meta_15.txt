# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- **Direct per-point iterative optimization remains the strongest observed pattern, and the current best program is the clearest example.** The **Active Contours / Physics-based Path Optimization** program is still the top performer at **14.19** with **F1 = 1.45, F2 = 0.32, F3 = 30.17**, outperforming the newer **Adam-Optimized Drone Polyline Path** (**14.60**, F1 = 1.65, F2 = 0.24, F3 = 36.09). Both optimize path coordinates directly rather than selecting from a fixed curve family, but the current best’s explicit decomposition into smoothness, school repulsion, and base attraction gives a better overall balance, especially on the dominant **F3** term.
- **Strong localized school repulsion combined with smoothness control consistently yields the best F2 values without destroying total score.** The current best uses a large Gaussian school-repulsion term (`beta = 5000.0`, `sigma_school = 20.0`) plus clipping and symmetry breaking, achieving **F2 = 0.32**. The Adam-based variant pushes school avoidance even harder to **F2 = 0.24**, but at the cost of much worse **F3 = 36.09**, confirming that aggressive repulsion works best when tightly integrated with balancing terms rather than optimized in partial isolation.
- **Localized base attraction is a key ingredient in all strong solutions, but it works best when embedded in coordinate-level updates rather than fixed-shape deformation.** The current best’s x-localized Gaussian base weighting reaches **F3 = 30.17**, substantially better than fixed deformation methods such as **Gaussian Route Builder** (**F3 = 33.28**, score **26.32**) and **Gaussian-Perturbed Sine Path** (**F3 = 33.56**, score **38.46**). This reinforces the earlier pattern that base-aware local influence is more effective than broad global bends.
- **Straight-line initialization followed by smooth deformation remains a reliable common structure among the strongest programs.** The current best starts from a straight line and iteratively deforms it; this same baseline appears in **Adam-Optimized Drone Polyline Path** (**14.60**), **Gaussian Route Builder** (**26.32**), and **Gaussian-Perturbed Sine Path** (**38.46**). The evidence continues to show that preserving a reasonable baseline and then applying controlled local modifications is superior to committing early to a rigid global shape.

## Ineffective Approaches
- **Keeping x-coordinates fixed while only partially optimizing y-values appears to limit tradeoff quality once the path model becomes competitive.** The evaluator explicitly flagged this in **Adam-Optimized Drone Polyline Path**: despite a strong score of **14.60**, fixed x positions likely restrict path flexibility. Its metrics illustrate the limitation: **excellent F2 = 0.24** but noticeably weaker **F3 = 36.09** and **F1 = 1.65** than the current best.
- **Builder-style or fixed-parameter Gaussian deformations remain too constrained to compete with active contour updates.** **Gaussian Route Builder** scored **26.32** with fixed repulsion/attraction strengths and spreads, and feedback noted that signal loss remained high. Likewise, **Gaussian-Perturbed Sine Path** scored **38.46** and still had **F3 = 33.56**. These methods improve geometry smoothly but do not adapt enough to the actual objective landscape.
- **Low-dimensional surrogate-guided parameter search can preserve path smoothness but still miss the real objective balance.** **Gaussian Heuristic Drone Path** used coarse amplitude grid search and local refinement yet scored a much worse **133.71**, with **F2 = 2.82** and **F3 = 44.10**. Even though it kept **F1 = 1.07**, the evaluation confirms again that optimizing a handcrafted proxy can severely underperform direct objective-aligned path updates.
- **Richer global basis models do not automatically translate into better total score when the search remains indirect.** **Smooth Basis CEM Drone Path** achieved a very good **F1 = 1.01** and respectable **F2 = 2.13**, but its **F3 = 40.61** led to a total score of **87.27**. This continues the prior trend that elaborate basis-function design is weaker than directly adjusting path points under localized school/base forces.

## Implementation Insights
- **The current best program’s effectiveness comes from explicit objective-aligned gradient components applied at every interior point.** Its code separately computes `grad_smooth`, `grad_school`, and `grad_base`, then combines them into one update. This clean decomposition matches its metric profile: **very low F2**, competitive **F3**, and only moderate **F1** inflation, producing the best overall balance among all summarized valid programs.
- **Gauss-Seidel-style in-place updates are a meaningful implementation advantage.** In the current best, each `y_coords[i]` is updated immediately inside the iteration loop, so subsequent points respond to already-adjusted neighbors during the same sweep. That mechanism is absent from the more template-driven methods and likely contributes to the best program’s stronger coordinated path shaping versus programs like **Gaussian Route Builder** and **Gaussian-Perturbed Sine Path**, which mainly apply one-shot deformations.
- **Stability controls enable much stronger localized forces without breaking correctness.** The current best uses gradient clipping to `[-50, 50]` and a small symmetry break when `dy_school` is near zero. These details are likely what make its very strong school repulsion numerically safe over **500 iterations**, helping it reach **F2 = 0.32**. The Adam-based polyline optimizer is also stable and correct, but its normalized multi-objective gradient still yields worse overall balance.
- **Direct optimization still beats refined search over smooth parameterized families even when those families are sophisticated.** **Smooth Basis CEM Drone Path** combined sinusoidal, quadratic, skew, and Gaussian bases with deterministic CEM, and **Gaussian Heuristic Drone Path** used amplitude search plus smoothing; neither came close to the current best. The implementation lesson from the evaluated results is that pointwise path updates aligned with the actual geometric forces are more impactful than increasing model complexity.

## Performance Analysis
- **The current best remains the top performer against all newly summarized valid programs.** At **14.19**, it still beats **Adam-Optimized Drone Polyline Path** at **14.60** by about **2.9%**, **Gaussian Route Builder** at **26.32** by about **46%**, **Gaussian-Perturbed Sine Path** at **38.46** by about **63%**, **Smooth Basis CEM Drone Path** at **87.27** by about **84%**, and **Gaussian Heuristic Drone Path** at **133.71** by about **89%**. This preserves the previously observed hierarchy: direct active-contour optimization remains clearly superior.
- **The best total score comes from balanced multi-objective behavior, not best-in-class performance on any single metric.** The current best does not have the lowest **F1** or **F2** among all candidates: **Adam-Optimized Drone Polyline Path** has lower **F2 = 0.24**, and several indirect methods have lower **F1**. But the current best’s **F3 = 30.17** is much better than Adam’s **36.09**, and that superior balance is what drives the best overall score.
- **F3 continues to be the main separator between competitive and noncompetitive methods.** The strongest two programs are **14.19 / F3 = 30.17** and **14.60 / F3 = 36.09**; the next tier, such as **Gaussian Route Builder** (**26.32 / F3 = 33.28**) and **Gaussian-Perturbed Sine Path** (**38.46 / F3 = 33.56**), already trails significantly despite decent **F1/F2**. The weakest methods all allow **F3** to rise toward or above **40**, and their total scores deteriorate sharply.
- **Very low F1 alone remains a poor predictor of strong MOP performance.** **Smooth Basis CEM Drone Path** (**F1 = 1.01**) and **Gaussian Heuristic Drone Path** (**F1 = 1.07**) both kept distance inflation low, yet their total scores were **87.27** and **133.71** because school/base tradeoffs were much worse. This further supports the established pattern that modestly higher path length is acceptable when it materially improves school avoidance and signal behavior.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Add a two-stage or smoothly annealed objective schedule inside the existing Gauss-Seidel pointwise solver.** Keep the same direct per-point update structure, but start with higher `beta` / lower `gamma` for early iterations to carve out school clearance, then gradually decrease `beta` and increase `gamma` so later sweeps focus on reducing `F3` near the base. This is strongly supported by the current best already having excellent `F2`, while the main remaining opportunity is to improve `F3` without giving back too much school avoidance.

2. **Replace the fixed global step size with a decayed learning rate plus per-term scaling or normalization.** For example, use a larger learning rate for the first 100–200 sweeps, then decay it, while also capping or normalizing `grad_school` and `grad_base` separately before summation so one term does not dominate due to raw magnitude. This is a low-risk mutation because it preserves the best program’s successful gradient decomposition and in-place updates, but may improve convergence balance beyond the current fixed `learning_rate = 0.1`.

3. **Add an explicit curvature regularizer beyond the current neighbor smoothness term.** A discrete second-difference or mild fourth-order smoothing term can be added to the update so the path resists sharp local bends while still allowing broad detours around the school and toward the base. This directly builds on the active-contour formulation and should let you safely use stronger localized forces, potentially improving `F3` and `F2` without inflating `F1` as much.

4. **Make base attraction adaptive to both horizontal proximity and current vertical error.** Instead of always applying `2 * gamma * weight_base * (y_curr - y_base)`, strengthen attraction only when `x_curr` is near the base and `|y_curr - y_base|` remains meaningfully large, or anneal `sigma_base` from wide to narrow across iterations. Evidence from the strongest programs suggests localized base-aware influence is crucial for lowering the dominant `F3`, and making it adaptive should outperform the current fixed Gaussian pull.

5. **Introduce tightly constrained x-coordinate optimization for a small window of points near the school/base region.** Keep endpoints fixed, preserve monotonic x ordering, and only allow small horizontal corrections for points whose `x` lies near `x_school` or `x_base`, with a strong penalty on x-movement to retain stability. This directly targets the main limitation seen in the strong Adam-based baseline—fixed x can trap the path in a suboptimal `F2/F3` tradeoff—while keeping the search much more controlled than full free-form 2D optimization.
