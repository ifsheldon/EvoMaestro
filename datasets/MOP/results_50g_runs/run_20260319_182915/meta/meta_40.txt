**Program Name: Straight-Line Y Interpolation**
- **Implementation**: The function extracts start/end coordinates and returns `num_points` intermediate Y values by linearly interpolating from `y_start` to `y_end` using a constant step `dy = (y_end - y_start) / (num_points + 1)`. By contrast, denser waypoint optimizers and more elaborate iterative relaxations remain worse.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Add a two-scale Gaussian basis while keeping the exact `proxy_score = F1 * F2 * F3` unchanged.** Keep the current 12 local controls, but append 4–6 broader Gaussians with centers spread across the route and `sigma` about `2x–4x` the current width, then optimize all amplitudes together. This is the most direct extension of the strongest pattern in the best and runner-up programs: compact smooth Gaussian parameterizations work, and extra coarse controls may improve global shaping for lower `F3` without damaging the already excellent `F2`.

2. **Expand the multi-start seeds with explicitly asymmetric school/base-aware templates.** In addition to the current 5×5 school/base scale grid, try deterministic seeds such as pre-school upward bump, post-school bump, left-heavy and right-heavy school repulsion, and a broad bridge-shaped bend between school and base. Recent results consistently show that structured seeding matters a lot, and asymmetry is a plausible missing ingredient because the current initialization mostly explores symmetric influence patterns.

3. **Augment coordinate descent with small adjacent block updates after each single-coordinate sweep.** For example, after testing each `c_ys[i]` alone, also test pair moves on `(i, i+1)` and occasional triple moves on `(i-1, i, i+1)` using a tiny grid like `{-h, 0, +h}` per variable, accepting only strict score improvements. This preserves the simplicity and exact-score alignment of the current best while addressing coordinated shape changes that single-variable moves may miss.

4. **Use a hierarchical coarse-to-fine search over the same Gaussian family.** First optimize a reduced model with 4 or 6 controls from the same exact product objective, then interpolate those amplitudes into the 12-control representation and run the existing local refinement. This follows the proven low-dimensional exact-product recipe but may improve basin selection before fine-scale descent commits to a locally good yet globally suboptimal route.

5. **Allow limited optimization of Gaussian center positions in critical x-regions while preserving sorted order.** Every few descent rounds, let one control center shift within a small window, with larger allowed movement for centers near the school x-position and base x-position, then re-evaluate with the same exact `F1 * F2 * F3` score. The current best already shows that representation quality is crucial, and reallocating control density toward the most decision-relevant regions is a targeted way to improve the `F2`/`F3` balance without abandoning the successful smooth low-parameter model.
