**Program Name: Straight-Line Y Interpolation**
- **Implementation**: The function extracts start/end coordinates and returns `num_points` intermediate Y values by linearly interpolating from `y_start` to `y_end` using a constant step `dy = (y_end - y_start) / (num_points + 1)`. # META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Add a two-scale Gaussian parameterization while keeping the exact `proxy_score = F1 * F2 * F3` objective unchanged.** Keep the current 12 evenly spaced controls, but add 4–6 broader Gaussian controls with `sigma` around `2x–4x` the current width and optimize all amplitudes jointly. This is the most direct extension of the strongest pattern seen in both the current best and the close runner-up: smooth low-dimensional bases work well, and extra coarse-scale freedom may improve large-route geometry and reduce `F3` without sacrificing the excellent `F2`.

2. **Enrich initialization with asymmetric, localized seed shapes near the school and base instead of only the current 5×5 symmetric scale sweep.** In addition to the existing school/base bias grid, explicitly try seeds such as a single pre-school bump, post-school bump, left-heavy repulsion around the school, right-heavy repulsion, and a broad bridge-shaped bend between school and base. Recent strong programs consistently benefit from structured multi-starts, and this change targets the likely missing basins where good `F2`/`F3` tradeoffs require asymmetry rather than globally symmetric deformation.

3. **Upgrade the local search from pure single-coordinate descent to include small neighboring block moves.** After each normal coordinate sweep, test joint updates on adjacent pairs or triples like `(i, i+1)` and `(i-1, i, i+1)` using a tiny candidate set such as `{-h, 0, +h}` per variable, accepting only strict score improvements. This stays faithful to the current best’s simple exact-score search, but it addresses a plausible limitation of one-at-a-time updates: some beneficial shape changes for school avoidance and base proximity are coordinated and cannot be reached through single-control moves alone.

4. **Introduce a hierarchical coarse-to-fine optimization schedule over the same Gaussian family.** First solve a smaller problem with 4 or 6 Gaussian controls, then interpolate that solution into the 12-control representation and run the existing refinement; optionally finish with the added broad controls from recommendation 1. This follows the best-performing template of compact smooth parameterization plus exact-product search, while improving global basin selection before fine control descent commits too early.

5. **Allow limited movement of Gaussian center locations in high-impact x-regions while preserving sorted order.** Start from the current evenly spaced `ctrl_xs`, but every few iterations allow one center at a time to shift within a small window, with stronger permission near the school x-position and base x-position and with monotonic ordering enforced. The current best already shows that representation quality matters a lot; reallocating control density toward the most decision-critical regions is a promising way to improve the balance of `F2` and `F3` without abandoning the proven smooth low-dimensional model.
