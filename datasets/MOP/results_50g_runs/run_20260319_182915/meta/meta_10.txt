# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- **Direct iterative optimization of the path itself remains the strongest pattern by a large margin.** The current best, **Gradient-Based Drone Path Optimizer**, achieves **14.19** with **F1 = 1.45, F2 = 0.32, F3 = 30.17** by repeatedly updating each intermediate `y` using explicit gradients for **smoothness + school repulsion + base attraction**. This clearly outperforms all newer fixed-shape and parameter-search variants, including **Gaussian Local Search Path** (**16.36**) and **Gaussian Grid Search Path Optimizer** (**16.52**), showing that pointwise active-contour-style refinement is still the most effective evaluated approach.
- **Strong localized school repulsion integrated into a smooth path model consistently produces very low F2.** The best program’s Gaussian school gradient with large repulsion strength (`beta = 5000.0`) drives **F2 down to 0.32**, better than **Gaussian Local Search Path** (**0.41**), **Gaussian Grid Search Path Optimizer** (**0.30**, slightly better on F2 alone but worse overall), and dramatically better than fixed-bend methods like **Cubic Bent Drone Path** (**1.43**) and **Smooth Basis CEM Drone Path** (**1.76**). Across results, the successful pattern is not just “bend away from school,” but doing so with a localized penalty coupled to smoothness control.
- **Localized base influence is more effective than broad global bending for reducing the dominant F3 term.** The current best uses an **x-localized Gaussian base weight** and gets **F3 = 30.17**, better than **Gaussian Local Search Path** (**29.63**, slightly lower F3 but worse total score), and much better than fixed-form methods such as **Cubic Bent Drone Path** (**43.08**), **Smooth Basis CEM Drone Path** (**40.15**), and **Gaussian Potential Field Path Bend** (**42.95**). This continues the prior pattern that base-aware localized attraction is materially more useful than a purely global downward detour.
- **Starting from a straight-line baseline and deforming it smoothly remains a reliable structural choice.** The current best, **Gaussian Local Search Path** (**16.36**), and **Gaussian Grid Search Path Optimizer** (**16.52**) all preserve a straight-line initialization and then apply controlled modifications. These all substantially outperform rigid handcrafted curves such as **Cubic Bent Drone Path** (**71.40**) and **Gaussian Potential Field Path Bend** (**93.24**), confirming that baseline-preserving deformation is a strong common ingredient in the best-performing valid programs.

## Ineffective Approaches
- **Fixed-form bends with manually chosen shape parameters consistently underperform.** **Cubic Bent Drone Path** uses a handcrafted cubic offset and scores **71.40** with **F3 = 43.08**; **Gaussian Potential Field Path Bend** uses a fixed Gaussian deflection and scores **93.24** with **F3 = 42.95**. In both cases, evaluation feedback explicitly notes that the path is valid but the score remains too high, with signal loss still dominating. These results reinforce that static path templates do not adapt well enough to the true tradeoff landscape.
- **More elaborate global basis models do not help when optimization is detached from the true objective geometry.** **Smooth Basis CEM Drone Path** combines sinusoidal/quadratic/skew/Gaussian bases and uses deterministic CEM, yet still scores only **71.29** with **F3 = 40.15**. Despite strong **F1 = 1.01**, its school/base tradeoff remained poor compared with the active-contour optimizer, indicating that broad basis-function search is less effective than direct pointwise adjustment.
- **Proxy-scored search improves over crude heuristics but still lags behind direct path optimization.** **Gaussian Grid Search Path Optimizer** (**16.52**) and **Gaussian Local Search Path** (**16.36**) are respectable and valid, but both remain worse than the current best **14.19**. Their summaries explicitly note that coarse Gaussian basis choices, surrogate scoring, or limited parameterized curve families likely cap solution quality. This matches earlier evidence that search over a low-dimensional proxy model does not fully capture the evaluator’s real objective.
- **Optimizing mainly for short distance while leaving F3 high leads to poor overall scores.** **Smooth Basis CEM Drone Path** has excellent **F1 = 1.01**, and **Cubic Bent Drone Path** and **Gaussian Potential Field Path Bend** also keep **F1** near **1.16**, but all three score very poorly overall because **F3 stays around 40–43**. The evaluated results continue to show that distance alone is not the limiting factor in total MOP performance.

## Implementation Insights
- **The current best program’s main advantage is its explicit per-point gradient decomposition aligned with the three objectives.** Its code computes `grad_smooth`, `grad_school`, and `grad_base` separately, then combines them into a single update. This maps directly onto the observed metric balance: **F2 is excellent (0.32)**, **F1 remains acceptable (1.45)**, and **F3 is substantially reduced (30.17)**. Compared with the parameter-search programs, this implementation is much closer to the actual evaluation structure.
- **In-place Gauss-Seidel updates appear to be an important implementation-level advantage.** The best program updates each `y_coords[i]` immediately inside the iteration loop, so later points in the same sweep react to already-improved neighbors. This likely helps the path settle coherently under the strong repulsion/attraction fields. None of the summarized fixed-template methods have a comparable mechanism, and even the strong **Gaussian Local Search Path** still operates in a more parameterized, indirect optimization space.
- **Stability controls in the best program are likely critical enablers of aggressive school repulsion.** Gradient clipping to `[-50, 50]` and the `dy_school` symmetry break when near zero allow the code to safely use a very large `beta = 5000.0` over **500 iterations**. That implementation detail aligns with the unusually strong **F2 improvement** relative to earlier Gaussian heuristics, which often had reasonable shaping ideas but lacked equally robust iterative update dynamics.
- **The strongest recent non-best programs still rely on smooth localized primitives, but in a more constrained way.** **Gaussian Local Search Path** uses Gaussian school repulsion, Gaussian base attraction, tilt, and cubic bend terms with coordinate descent; **Gaussian Grid Search Path Optimizer** precomputes Gaussian templates and searches amplitudes/widths. Their good-but-not-best scores (**16.36**, **16.52**) suggest that the primitives themselves are useful, but performance is higher when those effects are applied directly at the path-point level rather than through a small fixed parameter set.

## Performance Analysis
- **The current best remains the clear leader even against the newest valid programs.** Relative to **Gaussian Local Search Path** (**16.36**), the best score **14.19** is about **13% lower**; relative to **Gaussian Grid Search Path Optimizer** (**16.52**), it is about **14% lower**. The gap is much larger versus fixed-form methods: about **80% lower** than **Cubic Bent Drone Path** (**71.40**) and **Smooth Basis CEM Drone Path** (**71.29**), and about **85% lower** than **Gaussian Potential Field Path Bend** (**93.24**).
- **F3 continues to be the main quantity separating mediocre from strong solutions, but the very best score comes from balancing all three terms rather than minimizing F3 alone.** **Gaussian Local Search Path** achieves the best listed **F3 = 29.63**, slightly better than the current best’s **30.17**, yet its total score is worse (**16.36 vs. 14.19**) because its **F2 = 0.41** is higher and its overall tradeoff is less favorable. This is strong evidence that the best program’s advantage is multi-objective balance, not dominance on a single metric.
- **Low F1 by itself is a weak predictor of total quality.** Several much worse programs have better distance scores than the current best: **Smooth Basis CEM Drone Path** (**F1 = 1.01**), **Cubic Bent Drone Path** (**1.16**), and **Gaussian Potential Field Path Bend** (**1.16**). Their overall scores remain poor because **F3** stays high and school avoidance is weaker. The evaluated results consistently show that accepting a modestly worse path length can produce a much better MOP outcome.
- **There is now a clear performance hierarchy across evaluated approaches.** Straight-line or fixed-bend heuristics occupy the worst range (**71–96** among the cited methods), handcrafted Gaussian/sinusoidal deformations improved to the **30–40+** range in prior results, bounded parameter search brought scores down to the **16.x** range, and **iterative active-contour optimization** reached **14.19**. This progression strongly supports the earlier global insight that the major breakthrough came from moving from static geometry design to direct optimization of the path coordinates.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. **Replace the fixed learning rate with a staged schedule or per-term normalized updates.** Keep the current per-point gradient decomposition, but start with a larger step size for fast deformation and decay it over iterations, or scale each component (`grad_smooth`, `grad_school`, `grad_base`) so one term cannot dominate just because of raw magnitude. This is a low-risk extension of the current best program and is especially promising because the existing solver already works well but may be limited by `learning_rate=0.1` across all 500 iterations.

2. **Use multi-phase weighting: strong school repulsion early, stronger base attraction late.** For example, run the first 30–50% of iterations with very high `beta` and modest `gamma` to establish safe clearance, then gradually reduce `beta` and increase `gamma` so the path is pulled closer to the base once F2 is already under control. This directly follows the observed metric pattern: the best program already excels on F2, so the next gain likely comes from improving F3 without losing the school-avoidance structure.

3. **Add an explicit curvature-control term in addition to the current neighbor smoothness term.** A discrete second-difference or mild bi-Laplacian penalty can suppress sharp local kinks while still allowing large-scale detours around the school and toward the base. This is well aligned with the success of direct pointwise optimization: it preserves the active-contour framework but should allow more aggressive localized forces with less F1 damage.

4. **Make the base attraction more adaptive in both location and vertical error.** Instead of a fixed `gamma` and `sigma_base`, increase attraction only for points near the base in x and still far from `y_base`, or anneal `sigma_base` from wider to narrower so the path first notices the base region broadly and then locks in more precisely. This is strongly supported by the results: localized base influence is one of the few mechanisms that consistently improves the dominant F3 term.

5. **Introduce limited x-coordinate optimization for only a small subset of interior points near the school/base region.** Keep endpoints fixed and preserve monotonic x-order with strong regularization, but allow small horizontal shifts where vertical-only motion is restrictive. The current best likely benefits from the reduced search space, so this should be a tightly constrained mutation rather than a full 2D free-form path; the goal is to unlock better local F2/F3 tradeoffs without losing the stability of the existing method.
