An excellent way to improve the optimization of the drone path is to rethink the way the path is parameterized and how the proxy objective function evaluates it.

The previous code used only 3 global parameters (`a_school`, `a_base`, `a_global`) which severely limited the flexibility of the path, preventing it from finding complex curves that optimally balance the three objectives. Furthermore, the proxy score was a linear combination of the objectives, whereas the actual evaluation metric is a multiplier score (the product of F1, F2, and F3).

### Proposed Improvements:
1. **More Flexible Path Parameterization**: Instead of 3 global parameters, we will parameterize the path using 12 Gaussian "bumps" evenly distributed along the X-axis. This allows the path to bend locally and form much more complex and optimal shapes.
2. **Accurate Proxy Score**: We will change the proxy score to directly minimize the product of the three objectives (`F1 * F2 * F3`) rather than a linear combination. This perfectly aligns with the MOP Multiplier Score.
3. **Coordinate Descent Optimization**: We will use an iterative coordinate descent algorithm over the 12 bump weights. We will also initialize the search with a few heuristic paths (e.g., explicitly pushing away from the school and pulling towards the base station) to avoid getting stuck in poor local minima.
