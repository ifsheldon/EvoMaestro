<DESCRIPTION>
This algorithm uses a non-parametric "Deformable Path" approach optimized via Multi-Scale Windowed Coordinate Descent. Instead of relying on a fixed parametric curve (like Gaussians), it optimizes each Y-coordinate directly. To maintain smoothness and ensure global convergence, it applies perturbations using Gaussian-shaped windows of varying scales. 

1. **Multi-Scale Optimization**: It starts with large-scale windows (half the path length) to find the optimal global "bend" that avoids the school and approaches the base station. It then progressively reduces the window size to fine-tune local details.
2. **Coordinate Descent**: The algorithm iteratively adjusts the path, accepting only changes that improve a composite score of distance (F1), school proximity (F2), signal loss (F3), and a Laplacian smoothness penalty.
3. **Efficiency**: By using a truncated Gaussian kernel and a greedy local search, it explores a high-dimensional space (one variable per path point) much more effectively than a low-dimensional parametric model, allowing the path to "snake" around obstacles while remaining perfectly smooth.
