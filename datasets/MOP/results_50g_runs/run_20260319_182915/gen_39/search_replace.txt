<DESCRIPTION>
To improve the path optimization, we expand the initialization set with asymmetric and event-localized seeds instead of relying only on the symmetric `scale_s × scale_b` sweep. By introducing specific new basis functions (a bump before the school, a bump after the school, and a "bridge" bump between the school and base station), we can generate left-heavy, right-heavy, and bridge-focused repulsion strategies. This targeted basin coverage allows the surrogate model to evaluate and select from a much richer set of topological path candidates before performing local refinement, significantly lowering the combined multi-objective score.
