<DESCRIPTION>
Replace the naive straight-line interpolation with a smooth multi-objective path generator that combines:
1. a baseline straight line from start to end,
2. a localized repulsive bump away from the school at (approximately) (40, 20),
3. a localized attractive bump toward the base station at (approximately) (70, -30),
4. endpoint-preserving sinusoidal shaping so the curve stays smooth and does not create sharp kinks.

This is a targeted heuristic designed for the given objectives:
- F1 stays controlled because the path remains a smooth perturbation of the direct line.
- F2 improves by pushing the path away from the school’s Y level near its X location.
- F3 improves by bending the route toward the base station near its X location.

The implementation is adaptive to the actual provided `school` and `base` coordinates, while still matching the requested qualitative shape: away from (40, 20) and toward (70, -30).

def evolve_drone_path(start, end, school, base, num_points):
    """
    【无人机连续空间多目标折线优化】
    使用平滑启发式：
    1) 以起终点直线为基线，保证距离代价不过分恶化；
    2) 在学校附近加入“远离学校”的平滑斥力；
    3) 在基站附近加入“靠近基站”的平滑引力；
    4) 使用端点为零的正弦包络，避免折线出现突兀拐点。
    """
    import math

    x_start, y_start = start
    x_end, y_end = end
    sx, sy = school
    bx, by = base

    if num_points <= 0:
        return []

    dx_total = x_end - x_start
    if abs(dx_total) < 1e-9:
        return [float(y_start + (y_end - y_start) * (i + 1) / (num_points + 1)) for i in range(num_points)]

    def gauss(x, mu, sigma):
        sigma = max(float(sigma), 1e-6)
        z = (x - mu) / sigma
        return math.exp(-0.5 * z * z)

    y_coords = []
    base_line_span = abs(y_end - y_start)

    # 控制偏移幅度，尽量在提升 F2/F3 的同时维持较低 F1
    school_amp = 10.0 + 0.08 * abs(sy - (y_start + y_end) * 0.5)
    base_amp = 16.0 + 0.10 * abs(by - (y_start + y_end) * 0.5)

    # 学校附近影响稍窄，基站附近影响稍宽，形成平滑 S 型趋势
    school_sigma = max(abs(dx_total) * 0.12, 10.0)
    base_sigma = max(abs(dx_total) * 0.16, 12.0)

    for i in range(num_points):
        t = (i + 1) / (num_points + 1)
        x = x_start + dx_total * t

        # 基线：起点到终点线性过渡
        y_line = y_start + (y_end - y_start) * t

        # 端点为 0 的平滑包络，保证中段可弯折，两端自然收敛
        envelope = math.sin(math.pi * t)

        # 远离学校：如果当前基线在学校下方，则继续下压；反之上抬
        school_dir = -1.0 if y_line <= sy else 1.0
        school_push = school_dir * school_amp * gauss(x, sx, school_sigma)

        # 靠近基站：拉向基站 y 值
        base_pull = (by - y_line) * gauss(x, bx, base_sigma)

        # 组合并限制幅度，避免过度绕行
        offset = envelope * (school_push + 0.75 * base_pull)
        max_offset = 22.0 + 0.15 * base_line_span
        if offset > max_offset:
            offset = max_offset
        elif offset < -max_offset:
            offset = -max_offset

        y_coords.append(float(y_line + offset))

    return y_coords
