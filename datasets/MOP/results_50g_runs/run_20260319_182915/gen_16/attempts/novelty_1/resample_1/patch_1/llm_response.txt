Improve the path generator with two coordinated changes aimed at lowering combined score:

1) **Proxy objective upgrade**: add a **bi-Laplacian bending penalty** (4th-order smoothness) so the optimizer can maintain globally smooth curvature while still creating a stronger local deflection away from school and toward base. At the same time, slightly rebalance weights to prioritize school avoidance more (current F2 is the main weakness) while keeping distance and signal terms active.

2) **Deterministic post-CEM shape refinement**: replace simple averaging with a short, stable relaxation pass that combines:
- Laplacian + bi-Laplacian smoothing (smooth yet controllable bend),
- localized school repulsion around school x-position,
- localized base attraction around base x-position,
- mild tether to the current best path and baseline line.
This typically improves F2/F3 trade-off without introducing jaggedness or large F1 growth.

These edits are targeted, deterministic, and remain lightweight for runtime.
