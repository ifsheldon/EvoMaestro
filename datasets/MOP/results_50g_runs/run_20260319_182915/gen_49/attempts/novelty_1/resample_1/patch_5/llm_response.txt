<DESCRIPTION>
This update enhances the drone path parametrization and the optimization goal:
1.  **Two-Scale Gaussian Basis**: Adds 4 additional broad Gaussian basis functions to the `CurveGenerator` to allow for smoother global path shaping. This helps minimize F3 (signal loss) more effectively than local controls alone.
2.  **Product-Based Proxy**: Replaces the weighted sum in `SurrogateEvaluator` with a product-based objective (`f1 * f2 * f3`). This aligns the internal optimization with the external 'Multiplier Score' metric. It also improves the F2 proxy by using an inverse-square distance sum to better model noise potential.
3.  **Extended Search**: Updates the `LocalSearchOptimizer` to handle the new 10-dimensional parameter space and provides focused initial seeds for global shaping.
</DESCRIPTION>
