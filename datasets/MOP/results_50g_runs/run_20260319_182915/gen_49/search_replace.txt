This edit enhances the drone path parametrization and the optimization goal:
1.  **Two-Scale Gaussian Basis**: Adds 4 additional broad Gaussian basis functions (sigma = 0.4 * span) to the `CurveGenerator` to allow for smoother global path shaping. This helps minimize signal loss (F3) more effectively than local controls alone.
2.  **Product-Based Proxy**: Replaces the weighted sum in `SurrogateEvaluator` with a product-based objective (`f1 * f2 * f3`) plus a small smoothness penalty. This aligns the internal optimization with the external 'Multiplier Score' metric.
3.  **Extended Search**: Updates the `LocalSearchOptimizer` to handle the new 10-dimensional parameter space and provides focused initial seeds for global shaping.
