<DESCRIPTION>
This edit strengthens the current optimizer without rewriting the whole function.

The main idea is to keep the existing Gaussian-control representation, but make it much more search-efficient for the actual objective:

1. Add a smooth endpoint envelope to the Gaussian deformation basis, so bends naturally taper to zero near start/end. This usually reduces unnecessary path length inflation while preserving the ability to bend strongly near important regions.
2. Precompute basis values and score constants, making it cheap to evaluate many more candidate paths.
3. Replace the symmetric school/base initialization sweep with a richer seed set that is explicitly asymmetric and event-localized:
   - single bump before the school,
   - single bump after the school,
   - left-heavy school repulsion,
   - right-heavy school repulsion,
   - a bridge bump between school and base,
   - directional seeds that bend away from the school and toward the base.
4. Instead of optimizing only one best seed, rank all seeds and run coordinate descent from the top few. This increases basin coverage and is especially useful in this landscape where localized bends around the school and base matter more than globally symmetric perturbations.
5. Add a final light smoothing pass to preserve a smooth line shape while keeping the beneficial bend away from (40, 20) and toward (70, -30).

This is directly aimed at reducing the product F1 * F2 * F3 by improving initialization quality and preserving smoothness with lower distance overhead.
